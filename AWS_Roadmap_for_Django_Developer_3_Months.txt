Target:
- Python/Django Backend Developer

- Suggested study time: 2–3 hours/day
- Main stack: Django, Django REST Framework, PostgreSQL, Linux, Docker, GitHub Actions, AWS

===============================================================
RECOMMENDED DAILY ROUTINE
===============================================================

2–3 hours/day:

45 min  → Learn theory
60 min  → Hands-on AWS/Linux/Docker
30 min  → Django project
15 min  → Notes/review

Rule:
Do not only watch tutorials.
For every AWS service:
1. Learn what it does.
2. Create/use it.
3. Connect it with Django.
4. Delete unused resources.
5. Document what you learned.


===============================================================
IMPORTANT AWS SAFETY RULES
===============================================================

- Enable MFA on your AWS account.
- Do not expose AWS access keys in GitHub.
- Never commit .env files or secrets.
- Use IAM roles where possible.
- Use least-privilege permissions.
- Restrict Security Group ports.
- Monitor billing and budgets.
- Delete unused EC2/RDS/ALB/NAT resources.
- Be especially careful with NAT Gateway and other potentially
  chargeable resources.
- Use AWS documentation when configuring production systems.
