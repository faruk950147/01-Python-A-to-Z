
1 ====================================================================================
Python (OOP)-এ তিন ধরনের method আছে: Instance Method, Class Method, Static Method — এগুলোর কাজ আলাদা আলাদা।

1. Instance Method (ইনস্ট্যান্স মেথড)

এটা সবচেয়ে common method

বৈশিষ্ট্য:
প্রথম parameter হয় self
object (instance) দিয়ে call করা হয়
object-এর data (instance variable) access করতে পারে
উদাহরণ:
class Student:
    def __init__(self, name):
        self.name = name

    def show(self):   # instance method
        print(self.name)

s1 = Student("Faruk")
s1.show()

এখানে show() instance method কারণ এটা object-এর data ব্যবহার করছে।

2. Class Method (ক্লাস মেথড)

class level method

বৈশিষ্ট্য:
প্রথম parameter হয় cls
@classmethod decorator লাগে
class variable access/change করতে পারে
object ছাড়াও class দিয়ে call করা যায়
উদাহরণ:
class Student:
    school = "TMSS"

    @classmethod
    def change_school(cls, name):
        cls.school = name

Student.change_school("ABC School")
print(Student.school)
3. Static Method (স্ট্যাটিক মেথড)

সবচেয়ে independent method

বৈশিষ্ট্য:
self বা cls কিছুই লাগে না
@staticmethod decorator লাগে
class বা object data access করতে পারে না
শুধু utility কাজের জন্য
উদাহরণ:
class Math:
    @staticmethod
    def add(a, b):
        return a + b

print(Math.add(5, 3))
সহজভাবে মনে রাখো:
Type	কী ব্যবহার করে	কাজ
Instance Method	self	object data
Class Method	cls	class data
Static Method	কিছু না	সাধারণ কাজ

2 ====================================================================================

1. Instance Method (self)
def showName(self):
কেন ব্যবহার করি?
এটা object-specific data নিয়ে কাজ করে
প্রতিটা object-এর আলাদা data থাকে
উদাহরণ:
human = Human("Faruk", 22)
human.showName()

এখানে self.name → শুধু ওই object-এর name

2. Class Method (@classmethod)
@classmethod
def showClassName(cls):
কেন ব্যবহার করি?
এটা class নিজেকে represent করে
সব object-এর জন্য common data access করে
class variable modify করতে পারে
গুরুত্বপূর্ণ point:
self → object -> instance
cls → class -> classmethod
উদাহরণ:
Human.showClassName()

output:

Class Name: Human
Species: Homo sapiens
 কখন ব্যবহার করব?

✔ যখন class-level data দরকার
✔ যখন object ছাড়াই কাজ করতে চাই
✔ যখন class variable modify করতে চাই

3. Static Method (@staticmethod)
@staticmethod
def showClassInfo():
কেন ব্যবহার করি?
এটা না class use করে, না object use করে
শুধু utility function
উদাহরণ:
Human.showClassInfo()
কখন ব্যবহার করব?

✔ যখন function শুধু কাজ করবে
✔ কোনো self বা cls দরকার নেই
✔ helper function বানাতে চাই

সহজ comparison
Type	Access	Uses
Instance	self (object)	object data
Class	cls (class)	class data
Static	nothing	utility function
তোমার কোডের logic summary
Human class
│
├── instance method → person-specific info (name, age)
├── class method → class info (Human, Homo sapiens)
└── static method → general info (description)
ছোট tip (important)

তুমি চাইলে class method দিয়ে object createও করতে পারো:

@classmethod
def create_anonymous(cls):
    return cls("Unknown", 0)
