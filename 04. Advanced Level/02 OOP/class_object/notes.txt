# 1. Method কী?

Class-এর ভিতরে define করা function-কে সাধারণভাবে **method** বলা হয়।

Example:

```python
class Student:

    def show(self):
        print("Hello")
```

এখানে:

```python
show()
```

হলো একটি method।

Class:

```text
Student
   ↓
show()
   ↓
Method
```

Object তৈরি করে method call করা যায়:

```python
s = Student()

s.show()
```

# 3. Instance Method

**Instance Method** হলো এমন method যা একটি নির্দিষ্ট object/instance-এর data নিয়ে কাজ করে।

এটি Python-এ সবচেয়ে common method type।

## বৈশিষ্ট্য

```text
✔ সাধারণত প্রথম parameter self
✔ Object-এর মাধ্যমে call করা যায়
✔ Instance variable access করতে পারে
✔ প্রতিটি object-এর আলাদা data নিয়ে কাজ করতে পারে
```

## Example

```python
class Student:

    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)


s1 = Student("Faruk")

s1.show()
```

Output:

```text
Faruk
```

এখানে:

```python
self.name
```

এর মাধ্যমে `s1` object-এর `name` access করা হচ্ছে।

---

# 4. `self` কী?

`self` হলো current object/instance-কে represent করা একটি conventional parameter name।

Example:

```python
class Student:

    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)
```

যখন:

```python
s1 = Student("Faruk")

s1.show()
```

call করা হয়, তখন conceptually:

```python
Student.show(s1)
```

এর মতো কাজ করে।

অর্থাৎ:

```text
s1 → self
```

---

# 5. Instance Method-এর Formula

```text
Instance Method
       ↓
     self
       ↓
Current Object
       ↓
Instance Data
```

# 6. Class Method

**Class Method** হলো এমন method যা class-level data বা class-level behavior নিয়ে কাজ করে।

এটি:

```python
@classmethod
```

decorator ব্যবহার করে তৈরি করা হয়।

## বৈশিষ্ট্য

```text
✔ @classmethod ব্যবহার করে
✔ প্রথম parameter সাধারণত cls
✔ Class variable access করতে পারে
✔ Class variable পরিবর্তন করতে পারে
✔ Class অথবা object থেকে call করা যায়
✔ Alternative constructor তৈরি করতে পারে
```

## Example

```python
class Student:

    school = "TMSS"

    @classmethod
    def change_school(cls, name):
        cls.school = name


Student.change_school("ABC School")

print(Student.school)
```

Output:

```text
ABC School
```

---

# 7. `cls` কী?

`cls` হলো current class-কে represent করার conventional parameter name।

```text
self → Current Object

cls → Current Class
```

Example:

```python
class Student:

    school = "TMSS"

    @classmethod
    def show_school(cls):
        print(cls.school)
```

```text
Class Method
```

# 9. Static Method

**Static Method** এমন method যার জন্য Python automatically `self` বা `cls` pass করে না।

এটি সাধারণত utility/helper functionality-এর জন্য ব্যবহার করা হয়।

`@staticmethod` decorator ব্যবহার করা হয়।

## Example

```python
class Math:

    @staticmethod
    def add(a, b):
        return a + b


print(Math.add(5, 3))
```

Output:

```text
8
```

এখানে `add()`:

```text
self ব্যবহার করছে না
cls ব্যবহার করছে না
```

---

# 10. Static Method কখন ব্যবহার করব?

যখন:

```text
✔ self দরকার নেই
✔ cls দরকার নেই
✔ Class state দরকার নেই
✔ Instance state দরকার নেই
✔ একটি utility/helper functionality দরকার
```

Example:

```python
class Math:

    @staticmethod
    def square(n):
        return n * n
```

---

# 11. তিন ধরনের Method — Comparison

| Method          | First Parameter | Context     | Main Purpose          |
| --------------- | --------------- | ----------- | --------------------- |
| Instance Method | `self`          | Object      | Instance-specific কাজ |
| Class Method    | `cls`           | Class       | Class-level কাজ       |
| Static Method   | None            | Independent | Utility/helper        |

Memory:

```text
self → Object

cls → Class

Nothing → Utility
```

# 12. একই Class-এ তিন ধরনের Method

```python
class Human:

    species = "Homo sapiens"

    def __init__(self, name, age):
        self.name = name
        self.age = age

    # Instance Method
    def show_name(self):
        print(self.name)
        print(self.age)

    # Class Method
    @classmethod
    def show_class_info(cls):
        print(cls.__name__)
        print(cls.species)

    # Static Method
    @staticmethod
    def general_info():
        print("Human is a living organism.")
```

Relationship:

```text
Human
│
├── Instance Method
│      ↓
│   self → Object data
│
├── Class Method
│      ↓
│   cls → Class data
│
└── Static Method
       ↓
   Utility
```

# 13. Class Method দিয়ে Object Create

Class Method alternative constructor হিসেবেও ব্যবহার করা যায়।

```python
class Human:

    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod

```

Output:

```text

```

এখানে:

```python
return cls("Unknown", 0)
```

বর্তমান class-এর নতুন object তৈরি করছে।

# 15. Method Binding

Python-এ object-এর মাধ্যমে instance method access করলে method-এর সাথে object-এর connection তৈরি হয়।

এই process-কে **method binding** বলা হয়।

Example:

```python
class Student:

    def show(self):
        print("Hello")


s = Student()

s.show()
```

এখানে:

```python
s.show
```

হলো bound method।

---

# 16. Bound Method

**Bound Method** হলো এমন method object যা একটি নির্দিষ্ট instance-এর সাথে bound/attached থাকে।

```python
s.show
```

মানে:

```text
show method
     +
s object-এর context
     ↓
Bound Method
```

---

# 17. Bound Method কীভাবে কাজ করে?

```python
class Student:

    def show(self):
        print("Hello")


s = Student()

s.show()
```

Conceptually:

```python
s.show()
```

এর equivalent:

```python
Student.show(s)
```

অর্থাৎ:

```text
s → self
```

# 20. Method Overloading

**Method Overloading** বলতে একই method name ব্যবহার করে বিভিন্ন parameter list handle করাকে বোঝায়।

যেমন:

```text
add(a)

add(a, b)

add(a, b, c)
```

Java/C++-এর মতো language-এ traditional method overloading directly supported।

কিন্তু Python-এ traditional method overloading সরাসরি নেই।

---

# 21. Python-এ একই Method Name দুইবার



```text

     ↓
Replaced

     ↓

```

# 24. `*args`

Output:

```text

30

```

# 25. `**kwargs`

`**kwargs` বিভিন্ন সংখ্যক keyword arguments গ্রহণ করে।

```text
department : CSE
```

# 27. Method Overriding

**Method Overriding** হলো child class-এ parent class-এর method নতুন implementation দিয়ে redefine করা।

এর জন্য inheritance থাকতে হয়।

```text
Parent
  ↓
Method
  ↓
Child
  ↓
Same Method Name
  ↓
New Implementation
```

---

# 28. Method Overriding Example

```python
class Parent:

    def greet(self, name):
        print("Hello from Parent")


class Child(Parent):

    def greet(self, name):
        print("Hello from Child")


obj1 = Parent()
obj2 = Child()

obj1.greet("John")
obj2.greet("John")
```

Output:

```text
Hello from Parent
Hello from Child
```

---

# 29. Overriding-এর মূল শর্ত

```text
1. Inheritance থাকতে হবে
2. Parent-এ method থাকতে হবে
3. Child-এ একই method name থাকতে হবে
4. Child নতুন implementation দিতে পারে
5. Child object থেকে call করলে Child-এর implementation ব্যবহৃত হয়
```

---

# 30. Method Signature

Overriding করার সময় child method-এর signature parent method-এর সাথে compatible রাখা ভালো।

```python
class Parent:

    def greet(self, name):
        print("Hello")


class Child(Parent):

    def greet(self, name):
        print("Hi")
```

এখানে:

```text
greet(self, name)
```

দুই class-এই compatible।

# 31. `super()`

Child class থেকে parent class-এর implementation call করতে:

```python
super()
```

ব্যবহার করা যায়।

```python
class Parent:

    def greet(self, name):
        print("Hello from Parent")


class Child(Parent):

    def greet(self, name):
        super().greet(name)
        print("Hello from Child")


obj = Child()

obj.greet("John")
```

Output:

```text
Hello from Parent
Hello from Child
```

---

# 32. `super()` কী করছে?

```python
super().greet(name)
```

Parent-এর `greet()` implementation access করছে।

Flow:

```text
Child.greet()
     ↓
super().greet()
     ↓
Parent.greet()
```

# 33. Overloading vs Overriding

| বিষয়                       | Overloading                  | Overriding                       |
| -------------------------- | ---------------------------- | -------------------------------- |
| মূল ধারণা                  | Same name + different inputs | Child parent method redefine করে |
| Class                      | সাধারণত একই class            | Parent + Child                   |
| Inheritance                | প্রয়োজন নেই                  | প্রয়োজন                          |
| Python traditional support | সরাসরি নেই                   | আছে                              |
| উদ্দেশ্য                   | Different inputs handle করা  | Existing behavior redefine করা   |

Memory:

```text
Overloading
→ Same Class + Different Inputs

Overriding
→ Parent → Child + New Implementation
```

# 36. Duck Typing

Python-এ **Duck Typing** হলো এমন programming style যেখানে object-এর actual type-এর চেয়ে তার required behavior/capability গুরুত্বপূর্ণ।

মূল ধারণা:

```text
"If it walks like a duck
and quacks like a duck,
treat it like a duck."
```

অর্থাৎ:

```text
Object কোন class-এর?
        ↓
কম গুরুত্বপূর্ণ

Object required behavior দিতে পারে?
        ↓
গুরুত্বপূর্ণ
```

---

# 37. Duck Typing Example

```python
class Duck:

    def quack(self):
        print("Quack! Quack!")


class Person:

    def quack(self):
        print("I'm quacking like a duck!")


def make_it_quack(thing):
    thing.quack()


make_it_quack(Duck())
make_it_quack(Person())
```

Output:

```text
Quack! Quack!
I'm quacking like a duck!
```

---

# 38. Duck Typing কীভাবে কাজ করছে?

Function:

```python
def make_it_quack(thing):
    thing.quack()
```

এখানে function check করছে না:

```python
isinstance(thing, Duck)
```

বরং সরাসরি:

```python
thing.quack()
```

call করছে।

তাই:

```text
Duck
 ↓
quack() আছে
 ↓
Works
```

এবং:

```text
Person
 ↓
quack() আছে
 ↓
Works
```

# 43. Dynamic Typing বনাম Duck Typing

দুটো একই concept নয়।

### Dynamic Typing

Variable-এর type runtime-এ নির্ধারিত হতে পারে।

```python
x = 10
x = "Hello"
```

একই variable বিভিন্ন সময়ে বিভিন্ন type-এর object reference করতে পারে।

### Duck Typing

Object-এর actual type-এর পরিবর্তে তার behavior/capability-এর উপর গুরুত্ব দেওয়া হয়।

```text
Dynamic Typing
→ Type runtime-এ handled

Duck Typing
```

# 53. Stateful Callable Object

`__call__` ব্যবহার করে object function-এর মতো call হওয়ার পাশাপাশি নিজের state-ও ধরে রাখতে পারে।

```python
class Counter:

    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count


c = Counter()

print(c())
print(c())
print(c())
```

Output:

```text
1
2
3
```

---

# 54. Stateful কীভাবে?

প্রথমে:

```text

```

প্রথম call:

```text

```

দ্বিতীয় call:

```text
1 → 2
```

তৃতীয় call:

```text
2 → 3
```

অর্থাৎ object state মনে রাখছে।

# 57. `__init__` vs `__call__`

এটি খুব গুরুত্বপূর্ণ।



```text
 ↓
```

# 61. `__call__` এবং Class-Based Decorator

Class-based decorator তৈরিতেও `__call__` ব্যবহার করা যায়।

```python
class MyDecorator:

    def __init__(self, func):
        self.func = func

    def __call__(self):
        print("Before function")
        self.func()
        print("After function")


@MyDecorator
def hello():
    print("Hello")


hello()
```

Output:

```text
Before function
Hello
After function
```

---

# 62. `@MyDecorator` কী করছে?

এই:

```python

    print("Hello")
```

conceptually:

```python
def hello():
    print("Hello")


hello = MyDecorator(hello)
```

এর মতো।

তখন `hello` একটি callable decorator object হয়ে যায়।

কারণ:

```python
MyDecorator
```

class-এর মধ্যে আছে:

```python
def __call__(self):
```

```text
       ↓

       ↓

       ↓
```

# 64. `__call__` + Polymorphism

# 65. `__call__` + Duck Typing

```python
class Add:

    def __call__(self, a, b):
        return a + b


class Multiply:

    def __call__(self, a, b):
        return a * b


def calculate(operation, a, b):
    return operation(a, b)


print(calculate(Add(), 5, 3))
print(calculate(Multiply(), 5, 3))
```

Output:

```text
8
15
```

`calculate()` function জানে না object-এর type কী।

এটি শুধু ধরে নিচ্ছে:

```python
operation(a, b)
```

call করা যাবে।

এটাই duck-typing style behavior।

```text
        ↓
operation(a, b)
        ↓
Object callable?
        ↓
__call__()
        ↓
Specific implementation
```
