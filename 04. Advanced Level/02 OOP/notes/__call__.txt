Python-এ __call__ হলো একটি special (magic) method। এটি ব্যবহার করলে একটি object কে function এর মতো call করা যায়।

অর্থাৎ, যদি কোনো class-এ __call__ method থাকে, তাহলে সেই class-এর object-কে এমনভাবে ব্যবহার করা যাবে যেন সেটা একটা function।

1️⃣ Basic ধারণা
class Test:
    def __call__(self):
        print("Object called")

t = Test()
t()   # এখানে object কে function এর মতো call করা হচ্ছে

Output:

Object called

এখানে

t হলো object

t() call করলে Python ভিতরে t.__call__() execute করে।

2️⃣ Parameter সহ ব্যবহার
class Add:
    def __call__(self, a, b):
        return a + b

calc = Add()
print(calc(5, 3))

Output:

8

এখানে calc(5,3) মানে:

calc.__call__(5,3)
3️⃣ কেন ব্যবহার করা হয়

__call__ সাধারণত ব্যবহার করা হয় যখন:

1️⃣ Function-like object বানাতে
2️⃣ Stateful function তৈরি করতে
3️⃣ Decorator class বানাতে

4️⃣ Stateful Example
class Counter:
    def __init__(self):
        self.count = 0

    def __call__(self):
        self.count += 1
        return self.count

c = Counter()

print(c())
print(c())
print(c())

Output

1
2
3

এখানে object তার state (count) মনে রাখছে।

5️⃣ Real Life Example (Decorator)

অনেক Python class decorator এর ভিতরে __call__ ব্যবহার করে।

✅ সংক্ষেপে:

__call__ ব্যবহার করলে

object কে function এর মতো call করা যায়

obj()  →  obj.__call__()

class MultiplyLayer:

    def __init__(self, weight):
        self.weight = weight

    def __call__(self, x):
        return x * self.weight


layer = MultiplyLayer(10)

print(layer(5))
