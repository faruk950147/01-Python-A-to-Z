========================== Method Overloading ===========================

Python-এ Method Overloading বলতে বোঝায় একই ক্লাসে একই নামের একাধিক মেথড থাকা, কিন্তু তাদের parameter সংখ্যা বা type ভিন্ন থাকা। অর্থাৎ, একই নামের মেথড আলাদা আলাদা context এ ব্যবহার করা যায়।

কিন্তু Python-এ সরাসরি traditional method overloading নেই যেহেতু Python dynamically typed। অর্থাৎ, Python-এ যদি আপনি একই নামের মেথড দুইবার লিখেন, তাহলে শেষে লেখা মেথড আগেরটি override করে দেবে।

Python-এ method overloading করার উপায়

Python-এ method overloading সাধারণত default arguments, *args বা **kwargs ব্যবহার করে করা হয়।

1: Default arguments ব্যবহার করে
class Calculator:
    def add(self, a, b=0, c=0):
        return a + b + c

calc = Calculator()
print(calc.add(5))        # শুধু ১টি argument -> 5
print(calc.add(5, 10))    # ২টি argument -> 15
print(calc.add(5, 10, 15))# ৩টি argument -> 30

2: *args ব্যবহার করে
class Calculator:
    def add(self, *args):
        return sum(args)

calc = Calculator()
print(calc.add(5))            # 5
print(calc.add(5, 10))        # 15
print(calc.add(5, 10, 15))    # 30
Tip: Python-এ যেহেতু “duck typing” আছে, তাই method overloading এর চেয়ে *args বা type checking ব্যবহার করাই বেশি common।

========================== Method Overriding ===========================
Python-এ Method Overriding হলো inheritance (উত্তরাধিকার) ব্যবহার করে child class-এ parent class-এর কোনো মেথডকে পুনঃলিখন (override) করা। অর্থাৎ, child class-এর মেথড parent class-এর একই নামের মেথডকে replace করে।

এটা Polymorphism এর একটি ধরন।

1: উদাহরণ:
class Parent:
    def greet(self, name):
        print("Hello from Parent")

class Child(Parent):
    def greet(self, name):  # Parent-এর greet() method override করা হলো
        print("Hello from Child")

obj1 = Parent()
obj2 = Child()

obj1.greet("John")  # Output: Hello from Parent
obj2.greet("John")  # Output: Hello from Child

2: Key Points:

Method Overriding এ method name একই হতে হবে।

Parameter list সাধারণত same বা compatible হতে হয়।

Child class-এর method, parent class-এর method-এর behavior replace করে।

প্রয়োজনে super() ব্যবহার করে parent-এর original method call করা যায়:

class Child(Parent):
    def greet(self, name):
        super().greet(name)  # Parent class-এর greet() call করা
        print("Hello from Child")


3: Output:

Hello from Parent
Hello from Child


========================== Duck Typing ===========================
Python-এ Duck Typing হলো যখন একটি object এর মেথড বা প্রোপার্টি পরীক্ষা করা হয় না, বরং তার ব্যবহারের মতো পরীক্ষা করা। অর্থাৎ, একটি object এর মেথড বা প্রোপার্টি পরীক্ষা করা না, বরং তার ব্যবহারের মতো পরীক্ষা করা।

Python-এ Duck Typing হলো একটি concept যা বলে:

"যদি কোনো object হাঁটে যেমন হাঁস (walks like a duck) এবং তুইত্র (quacks like a duck), তাহলে সে object কে আমরা ‘duck’ ধরব।"

অর্থাৎ object-এর type-এর চেয়ে তার behavior বা methods/attributes গুরুত্বপূর্ণ।

Python-এ type checking সাধারণত কম ব্যবহার করা হয়, কারণ যদি object এর প্রয়োজনীয় method থাকে, তবে সেটা কাজ করবে।

উদাহরণ:
class Duck:
    def quack(self):
        print("Quack! Quack!")

class Person:
    def quack(self):
        print("I'm quacking like a duck!")

def make_it_quack(thing):
    thing.quack()  # এখানে type doesn't matter, শুধু quack() method আছে কি নেই তা important

duck = Duck()
person = Person()

make_it_quack(duck)    # Output: Quack! Quack!
make_it_quack(person)  # Output: I'm quacking like a duck!


ব্যাখ্যা:

make_it_quack() function কোনো type check করে না।

শুধু object-এর মধ্যে quack() method আছে কি নেই তা দেখে কাজ করে।

এজন্য Python-কে বলা হয় dynamically typed এবং duck typed।
