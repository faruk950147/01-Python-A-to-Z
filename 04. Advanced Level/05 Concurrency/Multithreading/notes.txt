# Python Threading & Multithreading — সহজ বাংলা নোট

## 1. Thread কী?

**Thread** হলো একটি **Process-এর ভিতরের ছোট execution unit বা execution path**।

একটি Process-এর মধ্যে এক বা একাধিক Thread থাকতে পারে।

Python program চালু হলে সাধারণত একটি **Main Thread** থাকে।

```text
Process
│
├── Main Thread
├── Worker Thread 1 → Task A
├── Worker Thread 2 → Task B
└── Worker Thread 3 → Task C
```

একই Process-এর Thread-গুলো সাধারণত একই **memory এবং resources** share করে।

### সহজ সংজ্ঞা

> **Thread হলো একটি Process-এর ভিতরের execution path।**

---

# 2. Threading কী?

**Threading** হলো একটি Process-এর মধ্যে একাধিক Thread ব্যবহার করে একাধিক কাজকে **concurrently** এগিয়ে নেওয়া।

Python-এ Threading করার জন্য built-in:

```python
import threading
```

Threading বিশেষভাবে **I/O-bound task**-এর জন্য উপকারী।

যেমন:

```text
API Request
Network Request
File Operation
Database Operation
Web Scraping
HTTP Request
External Service-এর জন্য অপেক্ষা
```

---

# 3. Concurrency কী?

**Concurrency** হলো একাধিক Task-এর execution এমনভাবে পরিচালনা করা যাতে তাদের কাজের সময় কিছু অংশ overlap করতে পারে।

```text
Task A ─────────────
Task B ─────────
Task C ────────────
```

### Concurrency

> একাধিক Task overlapping time period-এ progress করে।

### Parallelism

> একাধিক Task একই সময়ে বাস্তবে execute হয়, সাধারণত আলাদা CPU core-এ।

সহজভাবে:

```text
Concurrency
→ Task-গুলোর execution overlap করে।

Parallelism
→ Task-গুলো একই সময়ে execute হয়।
```

**মনে রাখবেন:** Concurrency মানেই একই মুহূর্তে execution নয়।

---

# 4. কেন Threading ব্যবহার করব?

ধরি আমাদের তিনটি I/O task আছে:

```text
Task A → 3 seconds
Task B → 3 seconds
Task C → 3 seconds
```

Sequentialভাবে করলে:

```text
Task A → 3 sec
Task B → 3 sec
Task C → 3 sec

Total ≈ 9 sec
```

Concurrency ব্যবহার করলে:

```text
Task A ─────────
Task B ─────────
Task C ─────────

Total may be closer to ≈ 3 sec
```

তবে Threading নির্দিষ্ট speedup **guarantee করে না**।

Performance নির্ভর করতে পারে:

```text
Network speed
Server response time
Operating system
Number of threads
I/O speed
CPU overhead
Application design
```

# 7. `start()` বনাম `run()`

## `start()`

```python
thread.start()
```

`start()` একটি **নতুন Thread** শুরু করে।

এটি Thread-এর `run()` method নতুন Thread-এর মধ্যে execute করে।

একটি Thread সাধারণত একবারই start করা যায়।

---

## `run()`

```python
thread.run()
```

`run()` Thread-এর actual কাজ ধারণ করে।

কিন্তু আমরা যদি সরাসরি:

```python
thread.run()
```

call করি, তাহলে নতুন Thread তৈরি হয় না।

Target function বর্তমান execution context-এই চলে।

### সহজ Rule

```text
start()
→ নতুন Thread শুরু করে

run()
→ সরাসরি বর্তমান execution context-এ কাজ চালায়
```

সাধারণভাবে ব্যবহার করব:

```python
thread.start()
```

# 8. `join()`

`join()` ব্যবহার করলে বর্তমান Thread অন্য Thread শেষ হওয়া পর্যন্ত অপেক্ষা করে।

```python
import threading
import time


def task():
    time.sleep(2)
    print("Task completed")


thread = threading.Thread(target=task)

thread.start()
thread.join()

print("Main thread finished")
```

এখানে:

```python
thread.join()
```

এর কারণে Main Thread অপেক্ষা করবে।

### গুরুত্বপূর্ণ

`join()` Thread বন্ধ করে না।

> `join()` শুধু Thread শেষ হওয়া পর্যন্ত অপেক্ষা করে।

# 9. Multiple Threads

```python
import threading
import time


def task(name):
    print(f"{name} started")

    time.sleep(2)

    print(f"{name} finished")


t1 = threading.Thread(
    target=task,
    args=("Thread 1",)
)

t2 = threading.Thread(
    target=task,
    args=("Thread 2",)
)

t3 = threading.Thread(
    target=task,
    args=("Thread 3",)
)


t1.start()
t2.start()
t3.start()


t1.join()
t2.join()
t3.join()


print("All tasks completed")
```

তিনটি Thread concurrentভাবে progress করতে পারে।

### Output order fixed নয়

যেমন:

```text
Thread 1 started
Thread 2 started
Thread 3 started
Thread 2 finished
Thread 1 finished
Thread 3 finished
```

অন্যবার order ভিন্ন হতে পারে।

কারণ Thread scheduling operating system এবং Python runtime-এর উপর নির্ভর করে।

# 16. Daemon Thread

**Daemon Thread** হলো একটি background Thread, যা কোনো non-daemon Thread বাকি না থাকলে Python process-কে alive রাখে না।

Example:

```python
import threading
import time


def background_task():

    while True:
        print("Background running...")
        time.sleep(1)


thread = threading.Thread(
    target=background_task,
    daemon=True
)

thread.start()

time.sleep(3)

print("Main program finished")
```

Python process শেষ হলে daemon Thread তার কাজ শেষ করবে—এমন guarantee নেই।

### গুরুত্বপূর্ণ কাজের জন্য daemon ব্যবহার না করাই ভালো

যেমন:

```text
Important Database Update
Important File Write
Financial Transaction
Critical Data Processing
```

এ ধরনের কাজের জন্য controlled shutdown ব্যবহার করা উচিত।

# 19. Race Condition

**Race Condition** হলো এমন সমস্যা যেখানে concurrent operation-এর timing বা order-এর উপর result নির্ভর করে।

যেমন:

```python
counter += 1
```

Conceptually এটি:

```text
Read counter
     ↓
Calculate new value
     ↓
Write new value
```

ধরি:

```text
Initial counter = 0

Thread 1 → Read 0
Thread 2 → Read 0

Thread 1 → Write 1
Thread 2 → Write 1
```

Expected:

```text
2
```

কিন্তু result হতে পারে:

```text
1
```

কারণ দুই Thread একই shared data synchronization ছাড়া access করেছে।

### Solution

```python
with lock:
    counter += 1
```

# 21. Lock

`Lock` ব্যবহার করা হয় Critical Section protect করার জন্য।

```python
import threading

lock = threading.Lock()
```

একটি normal `Lock` একসাথে সাধারণত মাত্র **একটি Thread** hold করতে পারে।

অন্য Thread একই locked Lock acquire করতে চাইলে অপেক্ষা করবে।

---

# 22. `acquire()` এবং `release()`

Manualভাবে Lock:

```python
lock.acquire()

# Critical Section

lock.release()
```

`acquire()` → Lock নেয়।

`release()` → Lock ছেড়ে দেয়।

### সমস্যা

যদি `release()` করার আগেই exception হয়, তাহলে Lock locked অবস্থায় থেকে যেতে পারে।

---

# 23. Safe Lock Management

`try/finally` ব্যবহার করা যায়:

```python
lock.acquire()

try:
    counter += 1

finally:
    lock.release()
```

Exception হলেও `finally` Lock release করবে।

---

# 24. `with lock` — Recommended

আরও সহজ ও নিরাপদ:

```python
with lock:
    counter += 1
```

Python নিজেই Lock acquire এবং release manage করে।

Complete example:

```python
import threading


counter = 0
lock = threading.Lock()


def increment():

    global counter

    for _ in range(100000):

        with lock:
            counter += 1


t1 = threading.Thread(target=increment)
t2 = threading.Thread(target=increment)


t1.start()
t2.start()


t1.join()
t2.join()


print(counter)
```

Expected:

```text
200000
```

কারণ shared update Lock দিয়ে protect করা হয়েছে।

# 26. RLock

`RLock` = **Reentrant Lock**

একটি Thread যদি ইতিমধ্যে RLock-এর owner হয়, তাহলে একই Thread আবার সেই Lock acquire করতে পারে।

```python
import threading

lock = threading.RLock()


def function_a():

    with lock:
        function_b()


def function_b():

    with lock:
        print("Running")


function_a()
```

এটি কাজ করবে কারণ একই Thread আবার RLock acquire করতে পারছে।

### Lock বনাম RLock

```text
Lock
→ Normal mutual-exclusion lock

RLock
→ একই Thread একই Lock বারবার acquire করতে পারে
```

RLock কয়বার acquire করা হয়েছে সেটি track করে।

তাই যতবার acquire করা হয়েছে, ততবার release করতে হয়।

# 27. Semaphore

**Semaphore** নির্ধারণ করে একই সময়ে সর্বোচ্চ কতগুলো Thread কোনো resource ব্যবহার করতে পারবে।

```python
import threading

semaphore = threading.Semaphore(3)
```

এখানে সর্বোচ্চ ৩টি Thread একসাথে Semaphore acquire করতে পারবে।

Example:

```python
import threading
import time


semaphore = threading.Semaphore(2)


def task(number):

    with semaphore:

        print(f"Thread {number} entered")

        time.sleep(2)

        print(f"Thread {number} leaving")


threads = []


for i in range(5):

    t = threading.Thread(
        target=task,
        args=(i,)
    )

    threads.append(t)
    t.start()


for t in threads:
    t.join()
```

এখানে একই সময়ে সর্বোচ্চ ২টি Thread protected section-এর ভিতরে থাকতে পারবে।

# 32. Condition

`Condition` ব্যবহার করা হয় যখন Thread-কে কোনো **specific state** হওয়ার জন্য অপেক্ষা করতে হয়।

```python
condition = threading.Condition()
```

Common methods:

```python
condition.wait()
condition.notify()
condition.notify_all()
```

Example:

```python
import threading
import time


condition = threading.Condition()


def consumer():

    with condition:

        print("Consumer waiting...")

        condition.wait()

        print("Consumer received signal")


def producer():

    time.sleep(2)

    with condition:

        print("Producer sending signal")

        condition.notify()


t1 = threading.Thread(target=consumer)
t2 = threading.Thread(target=producer)


t1.start()
t2.start()


t1.join()
t2.join()
```

বাস্তব producer-consumer code-এ সাধারণত state loop-এর মধ্যে check করা ভালো:

```python
with condition:

    while not data_available:
        condition.wait()
```

# 36. ThreadPoolExecutor

অনেক ছোট বা একই ধরনের Task থাকলে manually অনেক Thread তৈরি করা কঠিন হতে পারে।

তখন:

```python
from concurrent.futures import ThreadPoolExecutor
```

ব্যবহার করা যায়।

Example:

```python
from concurrent.futures import ThreadPoolExecutor
import time


def task(number):

    time.sleep(1)

    return number * number


with ThreadPoolExecutor(max_workers=3) as executor:

    results = executor.map(
        task,
        [1, 2, 3, 4, 5]
    )

    for result in results:
        print(result)
```

Output:

```text
1
4
9
16
25
```

এখানে:

```python
max_workers=3
```

মানে সর্বোচ্চ ৩টি worker Thread একসাথে ব্যবহার করা যাবে।

# 37. `submit()` এবং `Future`

`submit()` Thread Pool-এ একটি Task পাঠায়।

```python
from concurrent.futures import ThreadPoolExecutor
```

```text
25
```

# 41. Thread-Safe

কোনো code/resource যদি একাধিক Thread-এর concurrent access-এর সময় তার synchronization guarantees অনুযায়ী সঠিকভাবে কাজ করে, তাকে **thread-safe** বলা হয়।

Example:

```python
with lock:
    shared_data.append(item)
```

Lock shared operation protect করতে পারে।

### মনে রাখবেন

```text
Thread-safe ≠ Fast
```

Synchronization কিছু overhead তৈরি করতে পারে, কিন্তু correctness বজায় রাখতে সাহায্য করে।

# 42. Deadlock

**Deadlock** হলো এমন অবস্থা যেখানে দুই বা তার বেশি Thread একে অপরের দখলে থাকা resource-এর জন্য অনির্দিষ্টকাল অপেক্ষা করে।

Example:

```text
Thread A
   │
   ├── Lock 1 ✓
   │
   └── Waiting for Lock 2


Thread B
   │
   ├── Lock 2 ✓
   │
   └── Waiting for Lock 1
```

ফল:

```text
Thread A waits for Thread B
Thread B waits for Thread A
```

কেউই continue করতে পারে না।

---

# 43. Deadlock Prevent করার উপায়

## 1. একই Lock Order ব্যবহার করুন

সব Thread multiple Lock নিলে একই order অনুসরণ করবে।

```text
Lock A
   ↓
Lock B
```

অন্য Thread যেন না করে:

```text
Lock B
   ↓
Lock A
```

---

## 2. Lock Scope ছোট রাখুন

যতটুকু সময় Lock দরকার শুধু ততটুকু সময় Lock ধরে রাখুন।

খারাপ:

```python
with lock:
    perform_expensive_network_request()
    perform_large_computation()
    update_shared_data()
```

ভালো:

```python
data = perform_expensive_operation()

with lock:
    update_shared_data(data)
```

---

## 3. অপ্রয়োজনীয় Lock ব্যবহার করবেন না

যেখানে synchronization দরকার নেই সেখানে Lock ব্যবহার না করাই ভালো।

---

## 4. Timeout ব্যবহার করুন

কিছু synchronization operation-এ timeout দেওয়া যায়।

```python
if lock.acquire(timeout=2):

    try:
        # Critical section
        pass

    finally:
        lock.release()

else:
    print("Could not acquire lock")
```

Timeout সব Deadlock solve করে না, তবে কিছু ক্ষেত্রে forever waiting প্রতিরোধ করতে পারে।

# 49. GIL কী?

**GIL = Global Interpreter Lock**

Traditional CPython-এ GIL interpreter-এর internal state protect করে এবং একটি interpreter-এর মধ্যে এক সময়ে সাধারণত একটি Thread-কে Python bytecode execute করতে দেয়।

তাই CPU-bound pure-Python code-এ শুধু বেশি Thread তৈরি করলেই true multi-core parallelism পাওয়া যায় না।

Conceptually:

```text
CPU-bound Python code
        ↓
Traditional CPython GIL
        ↓
Multiple Thread সাধারণত
multi-core Python-bytecode execution দেয় না
        ↓
Multiprocessing useful হতে পারে
```

I/O-bound-এর ক্ষেত্রে:

```text
I/O-bound
    ↓
Thread waits for I/O
    ↓
Another Thread can make progress
    ↓
Threading useful
```

### Modern Python Note

Modern Python-এ free-threaded CPython builds-ও আছে যেগুলো traditional GIL ছাড়া run করতে পারে।

তাই:

> "Python has a GIL"

কথাটি মূলত traditional CPython execution-এর ক্ষেত্রে প্রযোজ্য।

# 54. Complete Threading Example

```python
import threading
import time


def task(name):

    print(f"{name} started")

    time.sleep(2)

    print(f"{name} finished")


threads = []


for i in range(3):

    thread = threading.Thread(
        target=task,
        args=(f"Thread-{i}",)
    )

    threads.append(thread)

    thread.start()


for thread in threads:

    thread.join()


print("All threads completed")
```

```text
Main Thread
    │
    ├── Thread-0
    │
    ├── Thread-1
    │
    └── Thread-2
           │
           ▼
        Complete
           │
           ▼
     Main Thread continues
```

## Q10. Lock কী?

Lock mutual exclusion প্রদান করে।

একসাথে সাধারণত মাত্র একটি Thread Lock hold করতে পারে।

---

## Q11. Lock এবং RLock-এর পার্থক্য কী?

```text
Lock
→ Normal mutual-exclusion lock

RLock
→ একই Thread একই Lock বারবার acquire করতে পারে
```

---

## Q12. Semaphore কী?

Semaphore একই সময়ে কতগুলো Thread resource ব্যবহার করতে পারবে তা limit করে।

```python
threading.Semaphore(3)
```

সর্বোচ্চ ৩টি Thread একসাথে acquire করতে পারে।

---

## Q13. Event কী?

Event হলো Thread-এর মধ্যে simple signaling mechanism।

---

## Q14. Condition কী?

Condition Thread-কে কোনো particular state-এর জন্য wait করতে এবং অন্য Thread-কে notify করতে সাহায্য করে।

---

## Q15. Queue কেন ব্যবহার করা হয়?

`Queue` thread-safe communication প্রদান করে।

বিশেষভাবে Producer-Consumer pattern-এ এটি খুব useful।

---

## Q16. Daemon Thread কী?

Daemon Thread হলো background Thread, যা কোনো non-daemon Thread বাকি না থাকলে Python process-কে alive রাখে না।

---

## Q17. GIL কী?

GIL = **Global Interpreter Lock**।

Traditional CPython-এ এটি একটি interpreter-এর মধ্যে এক সময়ে একটি Thread-কে Python bytecode execute করতে দেয়।

এটি CPU-bound pure-Python code-এর multi-core parallelism সীমিত করে।

---

## Q18. Threading কখন ব্যবহার করবেন?

বিশেষ করে I/O-bound task-এর ক্ষেত্রে:

```text
Network Requests
API Calls
File I/O
Database Operations
Web Scraping
```

---

## Q19. CPU-bound task-এর জন্য Threading ideal?

Traditional CPython-এ CPU-bound pure-Python code-এর জন্য সাধারণত ideal নয়, কারণ GIL-এর limitation আছে।

`multiprocessing` বেশি suitable হতে পারে।

---

## Q20. Deadlock কী?

যখন Thread-গুলো একে অপরের held resource-এর জন্য forever wait করে এবং কেউ continue করতে পারে না, তখন Deadlock হয়।

---

## Q21. Thread-Safe Code কী?

Multiple Thread concurrentভাবে access করলেও intended synchronization guarantees অনুযায়ী সঠিকভাবে কাজ করে এমন code হলো Thread-Safe Code।

---

## Q22. `join()` কি Thread stop করে?

না।

```python
thread.join()
```

শুধু Thread শেষ হওয়া পর্যন্ত wait করে।

---

## Q23. `run()` call করলে কি নতুন Thread তৈরি হয়?

না।

```python
thread.run()
```

বর্তমান execution context-এ কাজ চালায়।

নতুন Thread শুরু করতে:

```python
thread.start()
```

ব্যবহার করতে হয়।

---

## Q24. একটি Thread কি একাধিকবার start করা যায়?

না।

```python
thread.start()
thread.start()
```

সাধারণভাবে invalid।

নতুন Thread object তৈরি করতে হবে।

---

## Q25. Normal Thread কি target function-এর return value দেয়?

না।

Result সহজে পাওয়ার জন্য:

```python
ThreadPoolExecutor
```

এবং:

```python
Future
```

ব্যবহার করা যায়।
