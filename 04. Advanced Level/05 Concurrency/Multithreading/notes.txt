# Python Threading & Multithreading — Full Notes (বাংলা)

## 1. What Is a Thread?

Thread হলো একটি Process-এর মধ্যে execution-এর একটি পৃথক path। একটি Process-এর মধ্যে এক বা একাধিক Thread থাকতে পারে।

একই Process-এর Thread-গুলো সাধারণত Memory ও Resources Share করে।

## 2. What Is Threading?

Threading হলো একটি Process-এর মধ্যে একাধিক Thread ব্যবহার করে একাধিক কাজকে Concurrently এগিয়ে নেওয়া।

Python-এ Threading ব্যবহারের জন্য built-in threading module ব্যবহার করা হয়।

```python
import threading
```

Threading সাধারণত I/O-bound কাজের জন্য উপকারী, যেমন:
- API Requests
- Network Requests
- File Operations
- Database Operations
- Web Scraping

## 3. Concurrency vs Parallelism

Concurrency: একাধিক Task-এর Execution সময় পরস্পরের সঙ্গে Overlap করে। একটি Task অপেক্ষা করার সময় অন্য Task এগিয়ে যেতে পারে।

Parallelism: একাধিক Task একই সময়ে বাস্তবে Execute হয়, যেমন আলাদা CPU Core-এ।

Concurrency মানেই Parallelism নয়।

## 4. Why Use Threading?

ধরো, তিনটি I/O Task-এর প্রতিটির জন্য প্রায় ৩ সেকেন্ড অপেক্ষা করতে হয়।

Sequential Execution:
Task A → 3 seconds
Task B → 3 seconds
Task C → 3 seconds
Total ≈ 9 seconds

Concurrent Execution:
Task A, Task B, Task C একসঙ্গে Progress করতে পারে।
Total সময় প্রায় 3 seconds হতে পারে।

এটি একটি আনুমানিক উদাহরণ। বাস্তবে সময় নির্ভর করে I/O, Network ও Thread Overhead-এর ওপর।

## 5. Creating a Thread

```python
import threading

def task():
    print("Task is running")

thread = threading.Thread(target=task)
thread.start()
```

- threading.Thread() একটি Thread Object তৈরি করে।
- target=task দিয়ে কোন Function চালাতে হবে তা নির্ধারণ করা হয়।
- start() নতুন Thread শুরু করে।

সঠিক:
```python
thread = threading.Thread(target=task)
```

ভুল:
```python
thread = threading.Thread(target=task())
```

কারণ task() লিখলে Function-টি সঙ্গে সঙ্গে Call হয়। target=task লিখলে Function-টিকে Target হিসেবে দেওয়া হয়।

## 6. start() vs run()

start():
```python
thread.start()
```
নতুন Thread শুরু করে এবং সেই Thread-এর মধ্যে run() Execute করায়।

run():
```python
thread.run()
```
সরাসরি run() Call করলে নতুন Thread তৈরি হয় না। কাজটি বর্তমান Execution Context-এ চলে।

একটি Thread Object সাধারণত একবারই Start করা যায়।

## 7. join()

join() ব্যবহার করলে Calling Thread অন্য Thread শেষ হওয়া পর্যন্ত অপেক্ষা করে।

```python
import threading
import time

def task():
    time.sleep(2)
    print("Task completed")

thread = threading.Thread(target=task)
thread.start()
thread.join()

print("Main thread finished")
```

সম্ভাব্য Output:
```text
Task completed
Main thread finished
```

join() Thread বন্ধ করে না; এটি শুধু অপেক্ষা করে।

## 8. Multiple Threads

```python
import threading
import time

def task(name):
    print(f"{name} started")
    time.sleep(2)
    print(f"{name} finished")

t1 = threading.Thread(target=task, args=("Thread 1",))
t2 = threading.Thread(target=task, args=("Thread 2",))
t3 = threading.Thread(target=task, args=("Thread 3",))

t1.start()
t2.start()
t3.start()

t1.join()
t2.join()
t3.join()

print("All tasks completed")
```

Thread-গুলো Concurrently Progress করতে পারে। কোনটি আগে শেষ হবে তা নির্দিষ্ট নয়।

## 9. args and kwargs

args দিয়ে Positional Arguments পাঠানো হয়।

```python

def greet(name):
    print(f"Hello {name}")

thread = threading.Thread(target=greet, args=("Faruk",))
thread.start()
thread.join()
```

একটি Element-যুক্ত Tuple-এর শেষে Comma গুরুত্বপূর্ণ।

kwargs দিয়ে Keyword Arguments পাঠানো যায়।

```python
import threading

def student(name, age):
    print(name, age)

thread = threading.Thread(
    target=student,
    kwargs={"name": "Faruk", "age": 25}

thread.start()
thread.join()
```

## 10. Thread Name and Information

```python

    current = threading.current_thread()

thread = threading.Thread(target=task, name="Worker-1")

thread.join()
```

- current_thread(): বর্তমান Thread Object দেয়।
- name: Thread-এর নাম।
- ident: Thread Identifier।
- is_alive(): Thread Alive কি না জানায়।
- threading.active_count(): Active Thread-এর সংখ্যা জানায়।

## 12. Daemon Thread

Daemon Thread এমন Thread, যা একা Python Process-কে চালু রাখে না।

```python
thread = threading.Thread(target=task, daemon=True)
```

যখন সব Non-Daemon Thread শেষ হয়ে যায়, তখন Python Process বন্ধ হতে পারে, যদিও Daemon Thread-এর কাজ অসম্পূর্ণ থাকে।

### Daemon Thread-এর ব্যবহার

1. Background Monitoring
2. Periodic Status Checking
3. Non-Critical Logging
4. System Health Monitoring
5. Temporary Background Tasks
6. GUI Background Tasks
7. Progress Monitoring
8. Debugging Information Collection
9. Temporary Statistics Collection
10. Non-Critical Notifications

এই কাজগুলোতে Daemon Thread ব্যবহার করা যেতে পারে, যদি কাজটি অসম্পূর্ণ থাকলেও বড় সমস্যা না হয়।

### Daemon Thread Example

```python
import threading
import time

def background_task():
    while True:
        print("Background running...")
        time.sleep(1)

thread = threading.Thread(target=background_task, daemon=True)
thread.start()

time.sleep(3)
print("Main program finished")
```

Main Thread শেষ হওয়ার পর অন্য কোনো Non-Daemon Thread না থাকলে Process বন্ধ হতে পারে। Daemon Thread-এর কাজও বন্ধ হয়ে যেতে পারে।

Daemon Thread গুরুত্বপূর্ণ Data Save বা Cleanup শেষ করার নিশ্চয়তা দেয় না।

## 14. Non-Daemon Thread

Non-Daemon Thread চলতে থাকলে Python Process সাধারণত সেটির কাজ শেষ হওয়া পর্যন্ত চালু থাকে।

Python-এ Default হলো daemon=False।

Non-Daemon Thread কাজ শেষ করার সুযোগ দেয়, কিন্তু কাজ সফল হওয়ার নিশ্চয়তা দেয় না। Error Handling, Transaction Management ও Verification-ও প্রয়োজন।

## 15. Daemon vs Non-Daemon

Daemon Thread:
- Process Alive রাখে না।
- Process বন্ধ হলে কাজ অসম্পূর্ণ অবস্থায় বন্ধ হতে পারে।
- Non-Critical Background Task-এর জন্য উপযোগী হতে পারে।

Non-Daemon Thread:
- চলতে থাকলে Process সাধারণত Alive থাকে।
- গুরুত্বপূর্ণ কাজ সম্পন্ন করার সুযোগ দেয়।
- Default হলো daemon=False।

Background Thread মানেই Daemon Thread নয়। Background Thread Daemon অথবা Non-Daemon—দুই ধরনেরই হতে পারে।

## 16. Shared Resource

একাধিক Thread একই Data বা Resource ব্যবহার করলে তাকে Shared Resource বলা হয়।

উদাহরণ:
- Bank Balance
- Available Seats
- Shared File
- Database Record
- Shared Data Structure

একাধিক Thread একই Data পরিবর্তন করলে Synchronization প্রয়োজন হতে পারে।

## 17. Race Condition

Race Condition হলো এমন সমস্যা, যেখানে Concurrent Operation-এর ফলাফল Execution Timing বা Order-এর ওপর নির্ভর করে।

ধরো, counter = 0।

Thread 1 → Read 0
Thread 2 → Read 0
Thread 1 → Write 1
Thread 2 → Write 1

দুটি Increment হওয়ার কথা ছিল, তাই প্রত্যাশিত মান 2। কিন্তু শেষ মান 1 হতে পারে। এটিকে Lost Update বলা হয়।

## 18. Lock দিয়ে Race Condition সমাধান

```python
import threading

counter = 0
lock = threading.Lock()

def increment():
    global counter
    for _ in range(100000):
        with lock:
            counter += 1

t1 = threading.Thread(target=increment)
t2 = threading.Thread(target=increment)

t1.start()
t2.start()

t1.join()
t2.join()

print(counter)
```

Expected Output:
```text
200000
```

with lock ব্যবহার করে একই সময়ে একাধিক Thread-কে Protected Operation পরিবর্তন করা থেকে বিরত রাখা হয়েছে।

## 19. Critical Section

Critical Section হলো Code-এর এমন অংশ, যেখানে Shared Resource Access বা Modify করা হয় এবং Synchronization দরকার হতে পারে।

```python
with lock:
    counter += 1
```

এখানে counter += 1 হলো Critical Section-এর অংশ।

## 20. Lock

Lock ব্যবহার করে Critical Section-এ একই সময়ে মাত্র একটি Thread-এর প্রবেশ নিশ্চিত করা যায়।

```python
import threading
lock = threading.Lock()
```

acquire() Lock Acquire করে।
release() Lock Release করে।

```python
lock.acquire()
try:
    # Critical Section
    pass
finally:
    lock.release()
```

Recommended Method:
```python
with lock:
    counter += 1
```

with lock ব্যবহার করলে Python স্বয়ংক্রিয়ভাবে Lock Acquire ও Release পরিচালনা করে।

## 21. RLock

RLock-এর পূর্ণরূপ Reentrant Lock। একই Thread ইতিমধ্যে RLock-এর Owner হলে আবার সেই Lock Acquire করতে পারে।

```python
import threading

lock = threading.RLock()

def function_a():
    with lock:
        function_b()

def function_b():
    with lock:
        print("Running")

function_a()
```

Lock-এর ক্ষেত্রে একই Thread পুনরায় Acquire করলে সমস্যা হতে পারে; RLock-এ একই Thread পুনরায় Acquire করতে পারে। RLock যতবার Acquire করা হয়েছে, ততবার Release করতে হয়।

## 22. Semaphore

Semaphore নির্ধারণ করে একই সময়ে সর্বোচ্চ কতটি Thread কোনো Resource ব্যবহার করতে পারবে।

```python
import threading
semaphore = threading.Semaphore(3)
```

এখানে সর্বোচ্চ তিনটি Thread একসঙ্গে Semaphore Acquire করতে পারবে।

```python
import threading
import time

semaphore = threading.Semaphore(2)

def task(number):
    with semaphore:
        print(f"Thread {number} entered")
        time.sleep(2)
        print(f"Thread {number} leaving")

threads = []

for i in range(5):
    t = threading.Thread(target=task, args=(i,))
    threads.append(t)
    t.start()

for t in threads:
    t.join()
```

পাঁচটি Thread তৈরি হয়েছে, কিন্তু একই সময়ে সর্বোচ্চ দুটি Thread Protected অংশে প্রবেশ করতে পারবে।

## 23. Lock vs Semaphore

Lock:
- সাধারণত এক সময়ে একটি Thread Lock ধরে রাখে।
- Critical Section Protect করতে ব্যবহৃত হয়।

Semaphore(3):
- সর্বোচ্চ তিনটি Thread একসঙ্গে Semaphore Acquire করতে পারে।
- Concurrent Access-এর সংখ্যা সীমিত করে।

## 24. Event

Event হলো Thread-এর মধ্যে Simple Signaling Mechanism।

```python
event = threading.Event()
```

Methods:
- set(): Event Set করে।
- clear(): Event Clear করে।
- wait(): Event Set হওয়া পর্যন্ত অপেক্ষা করে।
- is_set(): Event Set হয়েছে কি না জানায়।

### Example

```python
import threading
import time

def worker(event):
    print("Thread is waiting...")
    event.wait()
    print("Thread received the signal!")

event = threading.Event()
thread = threading.Thread(target=worker, args=(event,))

thread.start()
time.sleep(2)

print("Sending signal...")
event.set()

thread.join()
```

Flow:
Worker Thread → event.wait() → Waiting → event.set() → Continue Execution

## 25. Condition

Condition ব্যবহার করা হয় যখন একটি Thread-কে কোনো নির্দিষ্ট State হওয়ার জন্য অপেক্ষা করতে হয়।

```python
condition = threading.Condition()
```

Methods:
- wait()
- notify()
- notify_all()

### Example

```python
import threading
import time

condition = threading.Condition()

def consumer():
    with condition:
        print("Consumer waiting...")
        condition.wait()
        print("Consumer received signal")

def producer():
    time.sleep(2)
    with condition:
        print("Producer sending signal")
        condition.notify()

t1 = threading.Thread(target=consumer)
t2 = threading.Thread(target=producer)

t1.start()
t2.start()

t1.join()
t2.join()
```

Production Code-এ Condition একটি Loop-এর মধ্যে যাচাই করা উচিত, কারণ Notification পেলেই কাঙ্ক্ষিত Condition সত্য হয়েছে এমন নিশ্চয়তা নেই।

```python
with condition:
    while not data_available:
        condition.wait()
```

## 26. Event vs Condition

Event:
- Simple Signaling।
- set() দিয়ে Signal দেয়।
- wait() ব্যবহার করে।

Condition:
- State-এর জন্য Wait ও Notification।
- notify() বা notify_all() ব্যবহার করে।
- নির্দিষ্ট Condition যাচাই করে কাজ করার জন্য উপকারী।

## 27. Queue

Python-এর Queue হলো Thread-Safe Data Structure। এটি এক Thread থেকে অন্য Thread-এ Data বা Task পাঠাতে সাহায্য করে।

```python
from queue import Queue

queue = Queue()
queue.put("Task 1")
queue.put("Task 2")

print(queue.get())
print(queue.get())
```

Output:
```text
Task 1
Task 2
```

Methods:
- put(): Queue-তে Data যোগ করে।
- get(): Queue থেকে Data নেয়।
- task_done(): একটি Task সম্পন্ন হয়েছে বলে জানায়।
- join(): সব Enqueued Task-এর Completion Notification না পাওয়া পর্যন্ত অপেক্ষা করে।

queue.join() এবং thread.join() এক জিনিস নয়।

## 28. Producer-Consumer Pattern

Producer Task তৈরি করে।
Queue Task জমা রাখে।
Consumer Queue থেকে Task নিয়ে Process করে।

Producer → Queue → Consumer → Process Task

ব্যবহার:
- Backend Systems
- Web Applications
- Task Processing
- Data Pipelines

## 29. ThreadPoolExecutor

ThreadPoolExecutor Worker Thread-এর একটি Pool Manage করে।

```python
from concurrent.futures import ThreadPoolExecutor
import time

def task(number):
    time.sleep(1)
    return number * number

with ThreadPoolExecutor(max_workers=3) as executor:
    results = executor.map(task, [1, 2, 3, 4, 5])
    for result in results:
        print(result)
```

Output:
```text
1
4
9
16
25
```

max_workers=3 মানে সর্বোচ্চ তিনটি Worker Thread একসঙ্গে কাজ করতে পারবে।

## 30. submit() and Future

submit() একটি Task Pool-এ পাঠায় এবং একটি Future Return করে।

```python
from concurrent.futures import ThreadPoolExecutor
import time

def task(x):
    time.sleep(2)
    return x * x

with ThreadPoolExecutor(max_workers=3) as executor:
    future = executor.submit(task, 5)
    print("Task submitted")
    result = future.result()
    print(result)
```

Output:
```text
Task submitted
25
```

Future হলো একটি Asynchronous Task-এর সম্ভাব্য Result-এর Representation।

Methods:
- result(): Result পাওয়া পর্যন্ত অপেক্ষা করে।
- done(): Task শেষ হয়েছে কি না জানায়।
- exception(): Task-এর Exception থাকলে তা জানায়।
- cancel(): Task শুরু না হয়ে থাকলে Cancel করার চেষ্টা করে।

## 31. Thread Exception Handling

```python
import threading

def task():
    try:
        result = 10 / 0
        print(result)
    except Exception as e:
        print("Error:", e)

thread = threading.Thread(target=task)
thread.start()
thread.join()
```

Output:
```text
Error: division by zero
```

Normal Thread-এর Target Function থেকে Exception বের হয়ে এলে Python সাধারণত সেই Thread-এর জন্য Exception Report করে। Exception স্বয়ংক্রিয়ভাবে start() Call-এ ফিরে আসে না।

ThreadPoolExecutor ব্যবহার করলে Exception Future-এর মধ্যে থাকে এবং future.result() Call করলে তা Raise হতে পারে।

## 32. Thread থেকে Return Value

সাধারণ threading.Thread Target Function-এর Return Value সরাসরি দেয় না। Result পাওয়ার সহজ উপায় হলো ThreadPoolExecutor।

```python
from concurrent.futures import ThreadPoolExecutor

def task():
    return 100

with ThreadPoolExecutor(max_workers=1) as executor:
    future = executor.submit(task)
    result = future.result()
    print(result)
```

Output:
```text
100
```

## 33. Thread-Safe

যে Code বা Resource Concurrent Access-এর সময়ও নির্ধারিত Synchronization Rules মেনে সঠিকভাবে কাজ করে, তাকে Thread-Safe বলা হয়।

```python
with lock:
    shared_data.append(item)
```

Thread-safe মানেই Fast নয়। Synchronization কিছু Overhead তৈরি করতে পারে, তবে Correctness বজায় রাখতে সাহায্য করে।

## 34. Deadlock

Deadlock হলো এমন অবস্থা, যেখানে দুই বা তার বেশি Thread একে অপরের দখলে থাকা Resource-এর জন্য অপেক্ষা করে এবং কেউ আর এগোতে পারে না।

Thread A:
- Lock 1 Acquire করেছে।
- Lock 2-এর জন্য অপেক্ষা করছে।

Thread B:
- Lock 2 Acquire করেছে।
- Lock 1-এর জন্য অপেক্ষা করছে।

ফলাফল:
Thread A waits for Thread B।
Thread B waits for Thread A।

## 35. Deadlock Prevention

1. সব Thread-এ একই Lock Order ব্যবহার করো।
2. Lock-এর Scope ছোট রাখো।
3. অপ্রয়োজনীয় Lock এড়িয়ে চলো।
4. প্রয়োজন অনুযায়ী Timeout ব্যবহার করো।

```python
if lock.acquire(timeout=2):
    try:
        # Critical section
        pass
    finally:
        lock.release()
else:
    print("Could not acquire lock")
```

Timeout সব Deadlock সমাধান করে না, তবে কিছু ক্ষেত্রে অনির্দিষ্টকাল অপেক্ষা করা প্রতিরোধ করতে পারে।

## 36. Web Request Example

```python
import threading
import requests

def download(url):
    try:
        response = requests.get(url, timeout=10)
        print(url, response.status_code)
    except requests.RequestException as e:
        print(f"Request failed for {url}: {e}")

urls = [
    "https://example.com",
    "https://python.org",
    "https://github.com"
]

threads = []

for url in urls:
    thread = threading.Thread(target=download, args=(url,))
    threads.append(thread)
    thread.start()

for thread in threads:
    thread.join()
```

Independent I/O-bound Request-এর ক্ষেত্রে Threading উপকারী হতে পারে।

Production Application-এ Connection Pooling, Request Timeout, Exception Handling, Rate Limit ও Thread Pool বিবেচনা করা উচিত।

## 37. Custom Thread Class

threading.Thread Inherit করে Custom Thread Class তৈরি করা যায়।

```python
import threading
import time

class VideoUploader(threading.Thread):
    def __init__(self, video):
        super().__init__()
        self.video = video

    def run(self):
        print(f"Started uploading {self.video}")
        time.sleep(1)
        print(f"Video uploaded: {self.video}")

thread = VideoUploader("video1.mp4")
thread.start()
thread.join()
```

এখানে run() Method-এর মধ্যে Thread-এর কাজ লেখা হয়েছে। start() Call করলে নতুন Thread-এর মধ্যে run() Execute হয়।

## 38. CPU-bound vs I/O-bound

CPU-bound Task:
- Large Mathematical Calculations
- Image Processing
- Heavy Computation
- CPU-intensive Algorithms

I/O-bound Task:
- API Requests
- Network Requests
- Database Operations
- File I/O
- Web Scraping

Traditional GIL-enabled CPython-এ Pure-Python CPU-bound Task-এর জন্য সাধারণ Threading সাধারণত Multi-core Parallelism দেয় না। Multiprocessing উপকারী হতে পারে।

I/O-bound কাজের জন্য Threading অনেক সময় ভালো ফল দেয়।

## 39. GIL

GIL-এর পূর্ণরূপ Global Interpreter Lock।

Traditional CPython-এ GIL একই Interpreter-এর মধ্যে এক সময়ে সাধারণত একটি Thread-কে Python Bytecode Execute করতে দেয়।

এ কারণে Pure-Python CPU-bound কাজের ক্ষেত্রে Thread বাড়ালেই Multi-core Parallelism পাওয়া যায় না।

I/O-bound কাজের ক্ষেত্রে Threading অনেক সময় উপকারী।

Modern Python-এ Free-threaded CPython Build-ও রয়েছে, যা GIL ছাড়া চলতে পারে। তাই Python Implementation ও Build বিবেচনা করতে হবে।

## 40. Threading vs Multiprocessing

Threading:
- Basic Unit: Thread
- একই Process-এর Memory Share করে
- Thread Creation Cost সাধারণত কম
- I/O-bound কাজের জন্য প্রায়ই উপকারী
- Traditional CPython-এ CPU-bound Python Code GIL দ্বারা সীমিত হতে পারে

Multiprocessing:
- Basic Unit: Process
- সাধারণত আলাদা Memory ব্যবহার করে
- Process Creation Cost তুলনামূলক বেশি
- CPU-bound Python কাজের জন্য Multi-core ব্যবহার করতে পারে
- IPC ও Process Synchronization প্রয়োজন হতে পারে

সহজ Rule:
I/O-bound → Consider Threading
CPU-bound Pure Python → Traditional CPython-এ Consider Multiprocessing

## 44. Complete Threading Example

```python
import threading
import time

def task(name):
    print(f"{name} started")
    time.sleep(2)
    print(f"{name} finished")

threads = []

for i in range(3):
    thread = threading.Thread(target=task, args=(f"Thread-{i}",))
    threads.append(thread)
    thread.start()

for thread in threads:
    thread.join()

print("All threads completed")
```

Flow:
Main Thread → Thread-0, Thread-1, Thread-2 → All Tasks Complete → Main Thread Continues

## 46. Interview Questions and Answers

Q1. Thread কী?
Answer: Thread হলো একটি Process-এর ভিতরের Execution Path।

Q2. Threading কী?
Answer: একাধিক Thread ব্যবহার করে একাধিক Task-কে Concurrently এগিয়ে নেওয়া।

Q3. Python-এ Thread কীভাবে তৈরি করবেন?
Answer:
```python
import threading
thread = threading.Thread(target=function)
thread.start()
```

Q4. start() কী করে?
Answer: নতুন Thread শুরু করে এবং সেই Thread-এর মধ্যে run() Execute করায়।

Q5. run() কী করে?
Answer: Thread-এর কাজ ধারণ করে। সরাসরি run() Call করলে নতুন Thread তৈরি হয় না।

Q6. join() কী করে?
Answer: Calling Thread-কে অন্য Thread শেষ হওয়া পর্যন্ত অপেক্ষা করায়।

Q7. Race Condition কী?
Answer: Concurrent Operation-এর ফলাফল Execution Timing বা Order-এর ওপর নির্ভর করলে Race Condition হতে পারে।

Q8. Race Condition কীভাবে Prevent করবেন?
Answer: প্রয়োজন অনুযায়ী Lock, RLock, Semaphore বা অন্য Synchronization Mechanism ব্যবহার করবেন।

Q9. Critical Section কী?
Answer: Shared Data Access বা Modify করার Code অংশ, যেখানে Synchronization দরকার হতে পারে।

Q10. Lock কী?
Answer: Lock একই সময়ে একাধিক Thread-কে Protected Critical Section-এ প্রবেশ করতে বাধা দেয়।

Q11. Lock ও RLock-এর পার্থক্য কী?
Answer: Lock সাধারণ Mutual Exclusion Lock। RLock একই Thread-কে একাধিকবার Acquire করতে দেয়।

Q12. Semaphore কী?
Answer: Semaphore একই সময়ে কতটি Thread কোনো Resource ব্যবহার করতে পারবে তা সীমিত করে।

Q13. Event কী?
Answer: Thread-এর মধ্যে Simple Signaling Mechanism।

Q14. Condition কী?
Answer: নির্দিষ্ট State-এর জন্য Wait ও Notification পরিচালনা করে।

Q15. Queue কেন ব্যবহার করা হয়?
Answer: Thread-safe Communication ও Producer-Consumer Pattern-এর জন্য।

Q16. Daemon Thread কী?
Answer: এমন Thread, যা একা Python Process-কে চালু রাখে না।

Q17. Non-Daemon Thread কী?
Answer: চলতে থাকলে Python Process সাধারণত তার কাজ শেষ হওয়া পর্যন্ত চালু থাকে।

Q18. Daemon Thread কি গুরুত্বপূর্ণ Email পাঠানোর জন্য উপযুক্ত?
Answer: শুধু Daemon Thread-এর ওপর নির্ভর করা উচিত নয়। Process বন্ধ হওয়ার সময় Email Sending অসম্পূর্ণ থাকতে পারে।

Q19. GIL কী?
Answer: Global Interpreter Lock। Traditional CPython-এ Python Bytecode Execution-এর Parallelism সীমিত করে।

Q20. Threading কখন ব্যবহার করবেন?
Answer: বিশেষত I/O-bound Task-এর জন্য, যেমন API Request, Network Request, File I/O ও Web Scraping।

Q21. CPU-bound Task-এর জন্য Threading কি Ideal?
Answer: Traditional GIL-enabled CPython-এ Pure-Python CPU-bound Task-এর জন্য Multiprocessing অনেক সময় বেশি উপযোগী।

Q22. Deadlock কী?
Answer: একাধিক Thread পরস্পরের দখলে থাকা Resource-এর জন্য অপেক্ষা করে কেউ এগোতে না পারলে Deadlock হয়।

Q23. Thread-Safe Code কী?
Answer: Concurrent Access-এর মধ্যেও নির্ধারিত Synchronization Rules মেনে সঠিকভাবে কাজ করে এমন Code।

Q24. join() কি Thread Stop করে?
Answer: না। এটি শুধু Thread শেষ হওয়া পর্যন্ত অপেক্ষা করে।

Q25. একটি Thread কি একাধিকবার Start করা যায়?
Answer: একই Thread Object সাধারণত একবারই Start করা যায়। আবার কাজ শুরু করতে নতুন Thread Object তৈরি করতে হবে।

Q26. Normal Thread কি Target Function-এর Return Value দেয়?
Answer: না। Return Value পাওয়ার জন্য ThreadPoolExecutor ও Future ব্যবহার করা যায়।
