# Python Context Manager

## ১. Context Manager কী?

**Context Manager** হলো Python-এর একটি feature, যা **resource-কে নিরাপদভাবে এবং automatically manage** করতে ব্যবহার করা হয়।

এটি নিশ্চিত করে যে কোনো resource:

1. ব্যবহারের আগে Open বা Acquire করা হবে।
2. নির্দিষ্ট block-এর মধ্যে ব্যবহার করা হবে।
3. ব্যবহার শেষে সঠিকভাবে Close বা Release করা হবে।

Context Manager সাধারণত **`with` statement**-এর সাথে ব্যবহার করা হয়।

### Basic Syntax

```python
with expression as variable:
    # resource ব্যবহার করুন
```

### Example

```python
with open("file.txt", "r") as file:
    data = file.read()
    print(data)
```

এখানে:

```text
open() → File open করে
with   → File-টি manage করে
read() → File read করে
exit   → File automatically close হয়
```

আমাদের manually লিখতে হয় না:

```python
file.close()
```

---

# ২. Context Manager কেন ব্যবহার করি?

Context Manager ছাড়া:

```python
file = open("file.txt", "r")

data = file.read()

file.close()
```

এখানে সমস্যা হলো, `file.close()` করার আগেই যদি কোনো error ঘটে, তাহলে file open অবস্থায় থেকে যেতে পারে।

Context Manager ব্যবহার করলে:

```python
with open("file.txt", "r") as file:
    data = file.read()
```

Python automatically cleanup handle করে।

### প্রধান সুবিধা

```text
Context Manager
      │
      ├── Resource setup / acquire
      ├── Resource ব্যবহার
      ├── Automatic cleanup
      └── Exception হলেও cleanup
```

### যেসব Resource manage করা যায়

Context Manager দিয়ে বিভিন্ন resource manage করা যায়:

```text
File
Database Connection
Network Connection
Lock
Socket
Temporary Resource
```

# ৩. Python `open()` এবং File Modes

`open()` function ব্যবহার করে file open করা হয়।

```python
open("file.txt", mode)
```

Common file modes:

| Mode | অর্থ                 |
| ---- | -------------------- |
| `r`  | Read                 |
| `w`  | Write / overwrite    |
| `a`  | Append               |
| `x`  | নতুন file তৈরি       |
| `r+` | Read এবং Write       |
| `b`  | Binary mode modifier |
| `t`  | Text mode modifier   |

### গুরুত্বপূর্ণ

`b` এবং `t` সাধারণত অন্য mode-এর সাথে ব্যবহার করা হয়।

Examples:

```text
rb → Read binary
wb → Write binary
rt → Read text
wt → Write text
```

---

# ৪. Read Mode — `r`

`r` মানে **Read**।

এটি একটি existing file reading-এর জন্য open করে।

```python
with open("file.txt", "r") as file:
    data = file.read()
    print(data)
```

যদি file-এর অস্তিত্ব না থাকে, Python:

```python
FileNotFoundError
```

দেবে।

### মনে রাখুন

```text
r → Read
```

---

# ৫. Write Mode — `w`

`w` মানে **Write**।

File না থাকলে এটি নতুন file তৈরি করে।

কিন্তু file আগে থেকেই থাকলে তার পুরোনো content **মুছে গিয়ে নতুন content দিয়ে replace হবে**।

```python
with open("file.txt", "w") as file:
    file.write("Hello, World!")
```

### Example

আগে ছিল:

```text
Hello
Python
```

`w` mode ব্যবহার করার পরে:

```text
Hello, World!
```

### মনে রাখুন

```text
w → Write + Overwrite
```

---

# ৬. Append Mode — `a`

`a` মানে **Append**।

এটি file-এর **শেষে নতুন data যোগ করে**।

পুরোনো content মুছে যায় না।

```python
with open("file.txt", "a") as file:
    file.write("Hello, World!")
```

যদি file-এর মধ্যে থাকে:

```text
Hello
```

Append করার পরে হবে:

```text
Hello
Hello, World!
```

যদি নতুন text নতুন line-এ লিখতে চান, তাহলে `\n` ব্যবহার করুন:

```python
with open("file.txt", "a") as file:
    file.write("\nHello, World!")
```

### মনে রাখুন

```text
a → File-এর শেষে নতুন data যোগ করা
```

# ৭. Read এবং Write Mode — `r+`

`r+` দিয়ে একই file-এ:

```text
Read
Write
```

দুটিই করা যায়।

File-টি আগে থেকেই থাকতে হবে।

```python
with open("file.txt", "r+") as file:
    data = file.read()
    print(data)

    file.write("Hello, World!")
```

### গুরুত্বপূর্ণ

`r+` automatically append করে না।

Write হবে **বর্তমান file position** থেকে।

উদাহরণস্বরূপ:

```python
file.read()
```

করার পরে file position সাধারণত file-এর শেষে চলে যায়।

তাই এরপর write করলে সাধারণত সেখানে write হবে।

যদি স্পষ্টভাবে file-এর শেষে write করতে চান:

```python
with open("file.txt", "r+") as file:
    data = file.read()

    file.seek(0, 2)
    file.write("Hello, World!")
```

এখানে:

```python
file.seek(0, 2)
```

file position-কে file-এর শেষে নিয়ে যায়।

### মনে রাখুন

```text
r  → Read
r+ → Read + Write
```

# ১২. Automatic Cleanup কীভাবে কাজ করে?

ধরুন:

```python

```

সাধারণ process হলো:

```text
Context Enter
      ↓
Resource Open
      ↓
Resource ব্যবহার
      ↓
Context Leave
      ↓
Resource Cleanup
```

`with` block-এর ভিতরে exception হলেও Context Manager cleanup করার সুযোগ পায়।

এটাই Context Manager-এর সবচেয়ে বড় সুবিধাগুলোর একটি।

# ১৩. Context Manager কীভাবে কাজ করে?

একটি custom Context Manager তৈরি করতে দুটি special method ব্যবহার করা যায়:

```python
__enter__()
__exit__()
```

এই method দুটি **Context Manager Protocol**-এর অংশ।

### Basic Example

```python
class MyContext:

    def __enter__(self):
        print("Entering context")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Exiting context")


with MyContext() as obj:
    print("Inside context")
```

Output:

```text
Entering context
Inside context
Exiting context
```

### Flow

```text
with MyContext()
       ↓
__enter__()
       ↓
with block
       ↓
__exit__()
```

---

# ১৪. `__enter__()` Method

`__enter__()` method Python যখন `with` block-এ প্রবেশ করে তখন call হয়।

Example:

```python
def __enter__(self):
    print("Entering context")
    return self
```

এটি সাধারণত ব্যবহার করা হয়:

```text
Resource Open করা
Resource Allocate করা
কোনো কিছু Initialize করা
Lock Acquire করা
Connection Open করা
```

`__enter__()` যে value return করে, `as`-এর পরের variable-এ সেই value পাওয়া যায়।

Example:

```python
with MyContext() as obj:
    print(obj)
```

এখানে `obj` পাবে:

```python
__enter__()
```

এর return করা value।

---

# ১৫. `__exit__()` Method

`__exit__()` method Python যখন `with` block থেকে বের হয় তখন call হয়।

```python
def __exit__(self, exc_type, exc_value, traceback):
    print("Exiting context")
```

এটি সাধারণত ব্যবহার করা হয়:

```text
Resource Close করা
Lock Release করা
Connection Close করা
Resource Cleanup করা
```

### `__exit__()` Parameters

```python
__exit__(self, exc_type, exc_value, traceback)
```

এগুলো exception সম্পর্কে information দেয়, যদি কোনো exception ঘটে।

```text
exc_type    → Exception-এর type
exc_value   → Exception object / value
traceback   → Traceback information
```

যদি কোনো exception না ঘটে, সাধারণত এগুলোর value হবে:

```text
None
None
None
```

# ১৬. Custom Context Manager Example

```python
class MyContext:

    def __enter__(self):

        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Resource released")


with MyContext():
    print("Working with resource")
```

Output:

```text
Resource acquired
Working with resource
Resource released
```

### সহজ Flow

```text
__enter__()
    ↓
Resource acquired
    ↓
with block
    ↓
__exit__()
    ↓
Resource released
```

# ১৭. `contextlib` ব্যবহার করে Context Manager

Python-এ `contextlib` নামে একটি module আছে।

এটি Context Manager সহজে তৈরি করতে সাহায্য করে।

আমরা `@contextmanager` decorator ব্যবহার করতে পারি।

```python
from contextlib import contextmanager


@contextmanager
def my_context():

    print("Resource acquired")

    try:
        yield

    finally:
        print("Resource released")


with my_context():
    print("Working with resource")
```

Output:

```text
Resource acquired
Working with resource
Resource released
```

---

# ১৮. `yield` সহ Context Manager

`@contextmanager` ব্যবহার করলে `yield` **setup এবং cleanup** অংশকে আলাদা করে।

Example:

```python
from contextlib import contextmanager


@contextmanager
def my_context():

    # Setup
    print("Start")

    try:
        yield

    finally:
        # Cleanup
        print("End")
```

Flow:

```text
Setup
  ↓
yield
  ↓
with block execute
  ↓
finally
  ↓
Cleanup
```

### সহজভাবে মনে রাখুন

```text
yield-এর আগে → Setup
yield-এর পরে → Cleanup
```

---

# ১৯. Context Manager এবং Exception

Context Manager-এর একটি বড় সুবিধা হলো exception ঘটলেও cleanup হয়।

Example:

```python
class MyContext:

    def __enter__(self):
        print("Resource acquired")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Resource released")


with MyContext():
    print("Working")

    raise ValueError("Something went wrong")
```

Exception report হওয়ার আগে output হবে:

```text
Resource acquired
Working
Resource released
```

কেন?

কারণ `with` block থেকে বের হওয়ার সময় Python:

```python
__exit__()
```

call করে।

Exception ঘটলেও `__exit__()` call করা হয়।

### গুরুত্বপূর্ণ

`__exit__()` exception suppress করতেও পারে।

যদি এটি:

```python
True
```

return করে, তাহলে exception suppress করা যেতে পারে।

আর যদি:

```python
False
```

অথবা:

```python
None
```

return করে, তাহলে exception সাধারণত আবার propagate করবে।

# Quick Revision Cheat Sheet

| Concept           | অর্থ                                |
| ----------------- | ----------------------------------- |
| `with`            | Context Manager ব্যবহার করে         |
| `__enter__()`     | Setup / Resource acquire            |
| `__exit__()`      | Cleanup / Resource release          |
| `@contextmanager` | সহজে Context Manager তৈরি করার উপায় |
| `yield`           | Setup এবং Cleanup আলাদা করে         |
| `r`               | Read                                |
| `w`               | Write / Overwrite                   |
| `a`               | Append                              |
| `x`               | নতুন File Create                    |
| `r+`              | Read + Write                        |
| `b`               | Binary                              |
| `t`               | Text                                |
