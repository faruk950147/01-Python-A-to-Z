# Python Command Line Arguments (বাংলা নোট)

## ১. Command Line Arguments কী?

**Command Line Arguments** হলো এমন কিছু value, যেগুলো আমরা Python program চালানোর সময় Terminal বা Command Prompt থেকে পাঠাই।

### উদাহরণ

```bash
python main.py 10 20 hello
```

এখানে:

```text
python   → Python interpreter
main.py  → Python script
10       → প্রথম argument
20       → দ্বিতীয় argument
hello    → তৃতীয় argument
```

Python program-এর ভিতরে এই value-গুলো ব্যবহার করা যায়।

### কেন Command Line Arguments ব্যবহার করি?

* Program চালানোর সময় input দেওয়ার জন্য।
* Filename, number ও text পাঠানোর জন্য।
* একই program বিভিন্ন input দিয়ে চালানোর জন্য।
* Automation script এবং command-line tools তৈরি করার জন্য।

---

## ২. `sys` Module কী?

Python-এর built-in `sys` module ব্যবহার করে command-line arguments access করা যায়।

```python
import sys

print(sys.argv)
```

Run:

```bash
python main.py 10 20 hello
```

Output:

```python
['main.py', '10', '20', 'hello']
```

এখানে সবচেয়ে গুরুত্বপূর্ণ variable হলো:

```python
sys.argv
```

---

## ৩. `sys.argv` কী?

`sys.argv` হলো একটি **list**, যেখানে সাধারণত script-এর নাম বা path এবং command-line arguments সংরক্ষিত থাকে।

### উদাহরণ

```python
import sys

print(sys.argv)
print(type(sys.argv))
```

Run:

```bash
python main.py 10 20 hello
```

Output:

```text
['main.py', '10', '20', 'hello']
<class 'list'>
```

### `sys.argv`-এর Index

```text
sys.argv[0] → Script-এর নাম বা path
sys.argv[1] → প্রথম user argument
sys.argv[2] → দ্বিতীয় user argument
sys.argv[3] → তৃতীয় user argument
```

**মনে রাখবে:** প্রথম user argument শুরু হয় index `1` থেকে, index `0` থেকে নয়।

## ৫. Command Line Arguments সবসময় String হিসেবে আসে

Command-line arguments Python-এ initially **string (`str`) হিসেবে পাওয়া যায়**।

উদাহরণ:

```bash
python main.py 10 20
```

Python পাবে:

```python
['main.py', '10', '20']
```

এখানে `'10'` একটি string, integer `10` নয়।

### Example

```python
import sys

num1 = sys.argv[1]
num2 = sys.argv[2]

print(num1)
print(type(num1))

print(num2)
print(type(num2))
```

Output:

```text
10
<class 'str'>
20
<class 'str'>
```

## ৬. Command Line Arguments-এর Type Conversion

String-কে number-এ রূপান্তর করতে `int()` অথবা `float()` ব্যবহার করি।

### Integer-এ Convert করা

```python
import sys

num1 = int(sys.argv[1])
num2 = int(sys.argv[2])

print(num1 + num2)
```

Run:

```bash
python main.py 10 20
```

Output:

```text
30
```

### Float-এ Convert করা

```python
import sys

num1 = float(sys.argv[1])
num2 = float(sys.argv[2])

print(num1 + num2)
```

Run:

```bash
python main.py 10 20
```

Output:

```text
30.0
```

### Conversion Flow

```text
Command Line Input
        |
        v
     "10" (str)
        |
        v
 int("10") অথবা float("10")
        |
        v
      10 অথবা 10.0
```

## ৭. Loop দিয়ে Arguments Access করা

`for` loop ব্যবহার করে `sys.argv`-এর সব element access করা যায়।

```python
import sys

args = sys.argv

print(args)
print(type(args))

for arg in args:
    print(arg)
```

Run:

```bash
python main.py 10 20 hello
```

Output:

```text
['main.py', '10', '20', 'hello']
<class 'list'>
main.py
10
20
hello
```

শুধু user arguments print করতে চাইলে:

```python
import sys

for arg in sys.argv[1:]:
    print(arg)
```

Output:

```text
10
20
hello
```

এখানে `sys.argv[1:]` ব্যবহার করে script name বাদ দেওয়া হয়েছে।

## ৮. `len(sys.argv)` কী?

`len(sys.argv)` list-এর মোট element সংখ্যা গণনা করে। এর মধ্যে script name-ও অন্তর্ভুক্ত থাকে।

```python
import sys

print(sys.argv)
print(len(sys.argv))
```

Run:

```bash
python main.py 10 20 hello
```

Output:

```text
['main.py', '10', '20', 'hello']
4
```

কারণ list-এ মোট চারটি element রয়েছে।

```text
sys.argv[0] → main.py
sys.argv[1] → 10
sys.argv[2] → 20
sys.argv[3] → hello
```

### গুরুত্বপূর্ণ

```python
len(sys.argv)
```

মোট element সংখ্যা দেয়।

```python
len(sys.argv) - 1
```

User-provided argument-এর সংখ্যা দেয়।

## ৯. Arguments-এর সংখ্যা Check করা

প্রয়োজনীয় arguments না থাকলে `sys.argv[1]` বা `sys.argv[2]` access করার সময় `IndexError` হতে পারে।

তাই আগে argument count check করা উচিত।

```python
import sys

if len(sys.argv) != 3:
    print("Usage: python main.py <num1> <num2>")
    sys.exit(1)

num1 = sys.argv[1]
num2 = sys.argv[2]

print(num1)
print(num2)
```

Run:

```bash
python main.py 10
```

Output:

```text
Usage: python main.py <num1> <num2>
```

এখানে `len(sys.argv) != 3` ব্যবহার করা হয়েছে, কারণ একটি script entry এবং দুটি user argument প্রয়োজন।

## ১০. `sys.exit()` কী?

`sys.exit()` ব্যবহার করে Python program বন্ধ করা যায়।

```python
import sys

print("Program started")

sys.exit(1)

print("This line will not execute")
```

Output:

```text
Program started
```

### Exit Codes

```text
sys.exit(0) → সাধারণত সফলভাবে program শেষ হয়েছে
sys.exit(1) → সাধারণত কোনো error বা failure হয়েছে
```

সাধারণ convention অনুযায়ী `0` success এবং nonzero exit code failure নির্দেশ করে।

---

## ১১. `try-except` দিয়ে Invalid Input Handle করা

User number-এর পরিবর্তে invalid text দিলে `int()` বা `float()` conversion-এ `ValueError` হতে পারে।

### Example

```python
import sys

if len(sys.argv) != 3:
    print("Usage: python main.py <num1> <num2>")
    sys.exit(1)

try:
    num1 = float(sys.argv[1])
    num2 = float(sys.argv[2])

except ValueError:
    print("Error: Please provide valid numbers.")
    sys.exit(1)

print(num1 + num2)
```

### Valid Input

```bash
python main.py 10 20
```

Output:

```text
30.0
```

### Invalid Input

```bash
python main.py abc 20
```

Output:

```text
Error: Please provide valid numbers.
```

এখানে `try-except` invalid input-এর error handle করে।

## ১২. Command Line Arguments দিয়ে File লেখা

Terminal থেকে filename এবং text পাঠিয়ে file তৈরি করা যায়।

File: `write_file.py`

```python
import sys

if len(sys.argv) != 3:
    print('Usage: python write_file.py <filename> "<text>"')
    sys.exit(1)

filename = sys.argv[1]
content = sys.argv[2]

with open(filename, "w", encoding="utf-8") as file:
    file.write(content)

print("File written successfully.")
```

Run:

```bash
python write_file.py message.txt "Hello World Python"
```

এতে `message.txt` নামে file তৈরি হবে এবং এর মধ্যে লেখা থাকবে:

```text
Hello World Python
```

**মনে রাখবে:** `"w"` mode-এ আগে থেকে থাকা file খুললে পুরোনো content overwrite হয়ে যায়।

---

## ১৩. Command Line Arguments দিয়ে File পড়া

Terminal থেকে filename পাঠিয়ে file-এর content পড়া যায়।

File: `read_file.py`

```python
import sys

if len(sys.argv) != 2:
    print("Usage: python read_file.py <filename>")
    sys.exit(1)

filename = sys.argv[1]

try:
    with open(filename, "r", encoding="utf-8") as file:
        content = file.read()

    print(content)

except FileNotFoundError:
    print(f"Error: File '{filename}' was not found.")
    sys.exit(1)
```

Run:

```bash
python read_file.py message.txt
```

Program file-এর content print করবে। File না থাকলে `FileNotFoundError` handle করবে।

## ১৬. Operator-সহ Calculator

এই calculator-এ Addition, Subtraction, Multiplication এবং Division করা যাবে।

File: `calculator.py`

```python
import sys

# Step 1: Check argument count
if len(sys.argv) != 4:
    print("Usage: python calculator.py <num1> <operator> <num2>")
    print('Example: python calculator.py 10 "+" 20')
    sys.exit(1)

# Step 2: Get arguments
num1 = sys.argv[1]
operator = sys.argv[2]
num2 = sys.argv[3]

# Step 3: Convert strings to numbers
try:
    num1 = float(num1)
    num2 = float(num2)

except ValueError:
    print("Error: Please provide valid numbers.")
    sys.exit(1)

# Step 4: Perform calculation
if operator == "+":
    result = num1 + num2

elif operator == "-":
    result = num1 - num2

elif operator == "*":
    result = num1 * num2

elif operator == "/":
    if num2 == 0:
        print("Error: Division by zero is not allowed.")
        sys.exit(1)

    result = num1 / num2

else:
    print("Error: Invalid operator.")
    print("Valid operators: +, -, *, /")
    sys.exit(1)

# Step 5: Display result
print(f"{num1} {operator} {num2} = {result}")
```

### Addition

```bash
python calculator.py 10 + 20
```

Output:

```text
10.0 + 20.0 = 30.0
```

### Subtraction

```bash
python calculator.py 20 - 10
```

Output:

```text
20.0 - 10.0 = 10.0
```

### Multiplication

```bash
python calculator.py 10 "*" 20
```

Output:

```text
10.0 * 20.0 = 200.0
```

### Division

```bash
python calculator.py 20 / 5
```

Output:

```text
20.0 / 5.0 = 4.0
```

### Division by Zero

```bash
python calculator.py 20 / 0
```

Output:

```text
Error: Division by zero is not allowed.
```

### কেন `*`-এর চারপাশে Quote ব্যবহার করি?

অনেক shell-এ `*` একটি wildcard হিসেবে কাজ করে এবং বর্তমান directory-এর filename-এর সঙ্গে match করতে পারে।

তাই নিরাপদভাবে লিখি:

```bash
python calculator.py 10 "*" 20
```

এটি Python-এর সমস্যা নয়; এটি shell-এর আচরণ।

## ২০. গুরুত্বপূর্ণ Interview Questions

### Q1. Command Line Arguments কী?

Program চালু করার সময় Terminal থেকে যে value-গুলো পাঠানো হয়, সেগুলোই Command Line Arguments।

### Q2. Command Line Arguments access করার জন্য কোন module ব্যবহার করা হয়?

Python-এর built-in `sys` module।

```python
import sys
```

### Q3. `sys.argv` কী?

`sys.argv` হলো একটি list, যেখানে script-এর নাম বা path এবং command-line arguments থাকে।

### Q4. `sys.argv[0]` কী রাখে?

সাধারণত script-এর নাম বা path রাখে।

### Q5. প্রথম user argument কোন index-এ থাকে?

```python
sys.argv[1]
```

### Q6. Command-line arguments-এর data type কী?

Initially এগুলো string হিসেবে আসে।

### Q7. `len(sys.argv)` কী করে?

Script name বা path-সহ list-এর মোট element সংখ্যা দেয়।

### Q8. কেন argument count check করতে হয়?

প্রয়োজনীয় argument আছে কি না নিশ্চিত করতে এবং `IndexError` এড়াতে।

### Q9. `sys.exit()` কী করে?

Python program বন্ধ করে এবং exit status ফেরত দিতে পারে।

### Q10. `try-except` কেন ব্যবহার করি?

Invalid string-কে number-এ convert করার সময় `ValueError`-এর মতো error handle করার জন্য।

### Q11. `sys.argv` এবং `argparse`-এর মধ্যে পার্থক্য কী?

`sys.argv` raw arguments-এর list দেয়। `argparse` দিয়ে named options, flags, type conversion, validation এবং help message সহজে তৈরি করা যায়।

4. `sys.argv[1]` হলো প্রথম user argument।
5. Arguments string হিসেবে আসে; প্রয়োজন হলে `int()` বা `float()` ব্যবহার করতে হয়।
6. Argument count check এবং `try-except` দিয়ে error handle করতে হয়।

### এক লাইনে সংজ্ঞা

**Command Line Arguments হলো Terminal থেকে Python program-এ পাঠানো value, যেগুলো `sys.argv` ব্যবহার করে access করা যায়।**

### পরবর্তী Topic

`sys.argv` শেখার পর Python-এর `argparse` module শেখা উচিত। এটি professional command-line application তৈরিতে বেশি সুবিধাজনক।
