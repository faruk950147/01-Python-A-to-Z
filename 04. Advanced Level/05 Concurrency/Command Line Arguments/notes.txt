# Python Command Line Arguments

## ১. Command Line Arguments কী?

**Command Line Arguments** হলো এমন কিছু value, যা আমরা কোনো Python program-কে **command line বা terminal থেকে run করার সময়** দিয়ে থাকি।

### Example

```bash
python main.py 10 20 hello
```

এখানে:

```text
main.py  → Python file / script
10       → প্রথম argument
20       → দ্বিতীয় argument
hello    → তৃতীয় argument
```

Python program-এর ভিতর থেকে আমরা এই value-গুলো read করতে পারি।

---

# ২. `sys` Module

Python-এ **command line arguments** নিয়ে কাজ করার জন্য `sys` module ব্যবহার করা যায়।

প্রথমে `sys` import করতে হবে:

```python
import sys
```

Command line arguments-এর জন্য সবচেয়ে গুরুত্বপূর্ণ variable হলো:

```python
sys.argv
```

---

# ৩. `sys.argv` কী?

`sys.argv` হলো একটি **list**, যেখানে command line arguments সংরক্ষিত থাকে।

### Example

ধরা যাক আমরা run করলাম:

```bash
python main.py 10 20 hello
```

তাহলে:

```python
sys.argv
```

এর মধ্যে থাকবে:

```python
['main.py', '10', '20', 'hello']
```

### Index-এর অর্থ

```text
sys.argv[0] → script-এর নাম
sys.argv[1] → প্রথম user argument
sys.argv[2] → দ্বিতীয় user argument
sys.argv[3] → তৃতীয় user argument
```

### গুরুত্বপূর্ণ

প্রথম user-provided argument শুরু হয় **index 1** থেকে, index 0 থেকে নয়।

# ৫. গুরুত্বপূর্ণ: `sys.argv`-এর Value সবসময় String

এটি সবচেয়ে গুরুত্বপূর্ণ বিষয়গুলোর একটি।

সব command line arguments শুরুতে **string** হিসেবে Python-এ আসে।

Example:

```bash
python main.py 10 20
```

Python পাবে:

```python
['main.py', '10', '20']
```

তাই:

```python
sys.argv[1]
```

এর value হলো:

```text
"10"
```

এটি:

```text
10
```

নয়।

এর type হলো:

```python
<class 'str'>
```

### Example

```python
import sys

num1 = sys.argv[1]
num2 = sys.argv[2]

print(num1)
print(type(num1))

print(num2)
print(type(num2))
```

Run:

```bash
python main.py 10 20
```

Output:

```text
10
<class 'str'>

20
<class 'str'>
```

# ৬. Command Line Arguments Convert করা

যেহেতু command line arguments string হিসেবে আসে, তাই অনেক সময় এগুলোকে number-এ convert করতে হয়।

## Integer-এ Convert

এর জন্য ব্যবহার করি:

```python
int()
```

Example:

```python
import sys

num1 = int(sys.argv[1])
num2 = int(sys.argv[2])

print(num1 + num2)
```

Run:

```bash
python main.py 10 20
```

Output:

```text
30
```

---

## Float-এ Convert

এর জন্য ব্যবহার করি:

```python
float()
```

Example:

```python
import sys

num1 = float(sys.argv[1])
num2 = float(sys.argv[2])

print(num1 + num2)
```

Run:

```bash
python main.py 10 20
```

Output:

```text
30.0
```

### মনে রাখবেন

```text
Command line
     ↓
  String
     ↓
int() / float()
     ↓
  Number
```

```python
print(args[0])
```

# ৮. `len(sys.argv)`

`len(sys.argv)` আমাদের বলে `sys.argv` list-এর মধ্যে মোট কয়টি item আছে।

Example:

```python
import sys

print(sys.argv)
print(len(sys.argv))
```

Run:

```bash
python main.py 10 20 hello
```

Output:

```text
['main.py', '10', '20', 'hello']
4
```

কেন `4`?

```text
sys.argv[0] → main.py
sys.argv[1] → 10
sys.argv[2] → 20
sys.argv[3] → hello
```

তাই মোট **৪টি item** আছে।

### গুরুত্বপূর্ণ

`len(sys.argv)`-এর মধ্যে **script-এর নামও count হয়**।

# ৯. Argument-এর সংখ্যা Check করা

আমরা যখন:

```python
sys.argv[1]
sys.argv[2]
```

ব্যবহার করব, তার আগে user প্রয়োজনীয় argument দিয়েছে কি না check করা ভালো।

Example:

```python
import sys

if len(sys.argv) < 3:
    print("Usage: python main.py <num1> <num2>")
    sys.exit(1)

num1 = sys.argv[1]
num2 = sys.argv[2]

print(num1)
print(num2)
```

যদি user run করে:

```bash
python main.py 10
```

তাহলে program দেখাবে:

```text
Usage: python main.py <num1> <num2>
```

এটি এমন error প্রতিরোধ করতে সাহায্য করে:

```text
IndexError: list index out of range
```

# ১০. `sys.exit()`

`sys.exit()` ব্যবহার করা হয় **program বন্ধ করার জন্য**।

Example:

```python
import sys

if len(sys.argv) < 3:
    print("Not enough arguments!")
    sys.exit(1)

print("Program continues...")
```

যদি প্রয়োজনীয় argument না থাকে:

```python
sys.exit(1)
```

তাহলে program বন্ধ হয়ে যাবে।

### Exit Codes

সাধারণভাবে:

```text
sys.exit(0) → সফলভাবে program শেষ হয়েছে
sys.exit(1) → Error / অসফলভাবে program শেষ হয়েছে
```

Non-zero exit code-এর নির্দিষ্ট অর্থ program অনুযায়ী আলাদা হতে পারে। তবে সাধারণ convention হলো:

```text
0 → Success
Non-zero → Error
```

# ১১. Command Line Arguments ব্যবহার করে File তৈরি করা

আমরা terminal থেকে filename এবং text পাঠাতে পারি।

### File: `file.py`

```python
import sys

if len(sys.argv) < 3:
    print("Usage: python file.py <filename> <text>")
    sys.exit(1)

filename = sys.argv[1]
text = sys.argv[2]

with open(filename, "w") as f:
    f.write(text)

print("File written successfully.")
```

Run:

```bash
python file.py filename.txt "Hello World"
```

এতে তৈরি হবে:

```text
filename.txt
```

এবং এর ভিতরে লেখা থাকবে:

```text
Hello World
```

# ১২. Command Line Arguments ব্যবহার করে File Read করা

আমরা terminal থেকে filename পাঠিয়ে file read-ও করতে পারি।

```python
import sys

if len(sys.argv) < 2:
    print("Usage: python file.py <filename>")
    sys.exit(1)

filename = sys.argv[1]

with open(filename, "r") as f:
    content = f.read()

print(content)
```

Run:

```bash
python file.py filename.txt
```

Program file-এর content read করে print করবে।

# ১৩. File Write এবং Read একসাথে

আমরা চাইলে দুইটি operation একসাথে করতে পারি।

```python
import sys

if len(sys.argv) < 3:
    print("Usage: python file.py <filename> <text>")
    sys.exit(1)

filename = sys.argv[1]
text = sys.argv[2]

# File-এ Write করা
with open(filename, "w") as f:
    f.write(text)

# File Read করা
with open(filename, "r") as f:
    print(f.read())
```

Run:

```bash
python file.py filename.txt "Hello World"
```

Output:

```text
Hello World
```

# ১৪. Space থাকা Text কীভাবে Handle করবেন?

কোনো argument-এর মধ্যে space থাকলে **quotes** ব্যবহার করতে হবে।

### সঠিক

```bash
python file.py message.txt "Hello World Python"
```

তাহলে:

```text
sys.argv[1] → message.txt
sys.argv[2] → Hello World Python
```

কিন্তু quotes ছাড়া:

```bash
python file.py message.txt Hello World Python
```

Python পাবে:

```text
sys.argv[1] → message.txt
sys.argv[2] → Hello
sys.argv[3] → World
sys.argv[4] → Python
```

### মনে রাখবেন

```text
"Hello World Python"
        ↓
একটি argument
```

কিন্তু quotes ছাড়া:

```text
Hello World Python
        ↓
তিনটি argument
```

# ১৫. Simple Calculator

আমরা command line arguments ব্যবহার করে একটি calculator তৈরি করতে পারি।

### File: `calculator.py`

```python
import sys

# Argument check করা
if len(sys.argv) != 3:
    print("Usage: python calculator.py <num1> <num2>")
    sys.exit(1)

# Arguments নেওয়া
num1 = sys.argv[1]
num2 = sys.argv[2]

# Float-এ convert করা
try:
    num1 = float(num1)
    num2 = float(num2)

except ValueError:
    print("Please provide valid numbers.")
    sys.exit(1)

# Addition
result = num1 + num2

print(f"The sum of {num1} and {num2} is {result}")
```

Run:

```bash
python calculator.py 10 20
```

Output:

```text
The sum of 10.0 and 20.0 is 30.0
```

# ১৬. Operator সহ Calculator

আমরা user-কে operator নির্বাচন করার সুযোগ দিতে পারি।

### File: `calculator.py`

```python
import sys

# Argument-এর সংখ্যা check করা
if len(sys.argv) != 4:
    print("Usage: python calculator.py <num1> <operator> <num2>")
    print("Operators: +, -, *, /")
    sys.exit(1)

# Arguments নেওয়া
num1 = sys.argv[1]
operator = sys.argv[2]
num2 = sys.argv[3]

# Number convert করা
try:
    num1 = float(num1)
    num2 = float(num2)

except ValueError:
    print("Please provide valid numbers.")
    sys.exit(1)

# Calculation করা
if operator == "+":
    result = num1 + num2

elif operator == "-":
    result = num1 - num2

elif operator == "*":
    result = num1 * num2

elif operator == "/":

    if num2 == 0:
        print("Error: Division by zero is not allowed.")
        sys.exit(1)

    result = num1 / num2

else:
    print("Invalid operator!")
    print("Use one of: +, -, *, /")
    sys.exit(1)

print(f"{num1} {operator} {num2} = {result}")
```

# ১৮. `*` কেন Quote করতে হয়?

অনেক command-line shell-এ `*`-এর একটি বিশেষ অর্থ আছে।

উদাহরণ:

```bash
python calculator.py 10 * 20
```

Shell `*`-কে current directory-এর file name দিয়ে replace করে দিতে পারে।

তাই নিরাপদভাবে লিখুন:

```bash
python calculator.py 10 "*" 20
```

অথবা:

```bash
python calculator.py 10 '*' 20
```

### গুরুত্বপূর্ণ

এটি মূলত **shell-এর behavior**, Python-এর সমস্যা নয়।

# ১৯. Command Line Arguments-এর সাথে `try-except`

Command line arguments string হিসেবে আসে।

যদি কোনো invalid string-কে number-এ convert করার চেষ্টা করি, তাহলে Python `ValueError` দেয়।

Example:

```python
import sys

if len(sys.argv) != 3:
    print("Usage: python main.py <num1> <num2>")
    sys.exit(1)

try:
    num1 = float(sys.argv[1])
    num2 = float(sys.argv[2])

except ValueError:
    print("Please provide valid numbers.")
    sys.exit(1)

print(num1 + num2)
```

### Valid Input

```bash
python main.py 10 20
```

Output:

```text
30.0
```

### Invalid Input

```bash
python main.py abc 20
```

Output:

```text
Please provide valid numbers.
```

### `try-except` কেন ব্যবহার করি?

কারণ:

```python
float("abc")
```

চালালে:

```text
ValueError
```

হয়।

`try-except` ব্যবহার করলে আমরা এই error সুন্দরভাবে handle করতে পারি।

# ২৫. Final Summary

### Command Line Arguments

**Command Line Arguments** হলো এমন value যা terminal থেকে Python program run করার সময় program-কে দেওয়া হয়।

Python-এ এগুলো access করার জন্য `sys` module ব্যবহার করা যায়।

```python
import sys
```

এর প্রধান variable হলো:

```python
sys.argv
```

`sys.argv` হলো একটি **list of strings**।

### Example

Command:

```bash
python main.py 10 20 hello
```

তাহলে `sys.argv` হবে:

```python
['main.py', '10', '20', 'hello']
```

অর্থাৎ:

```text
sys.argv[0] → main.py
sys.argv[1] → 10
sys.argv[2] → 20
sys.argv[3] → hello
```

### এই ৬টি বিষয় মনে রাখুন

```text
1. sys import করুন
       ↓
   import sys

2. sys.argv ব্যবহার করুন
       ↓
   sys.argv

3. সাধারণত script name থাকে argv[0]-এ
       ↓
   sys.argv[0]

4. প্রথম user argument হলো argv[1]
       ↓
   sys.argv[1]

5. Arguments শুরুতে string
       ↓
   int() / float() প্রয়োজন অনুযায়ী ব্যবহার করুন

6. Error handle করুন
       ↓
   len(sys.argv)
   try-except
   sys.exit()
```
