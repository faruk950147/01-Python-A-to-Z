# Python Multiprocessing — Complete বাংলা Notes

## ১. Processing কী?

**Processing** বলতে input বা data নিয়ে কাজ করে useful output তৈরি করাকে বোঝায়।

Python-এ কাজ সম্পন্ন করার বিভিন্ন পদ্ধতি রয়েছে:

- **Single Processing:** সাধারণত একটি process-এর মধ্যে কাজ সম্পন্ন করা।
- **Multithreading:** একটি process-এর মধ্যে একাধিক thread ব্যবহার করা।
- **Multiprocessing:** একাধিক process ব্যবহার করে কাজ সম্পন্ন করা।
- **Asynchronous Programming:** কোনো কাজের জন্য অপেক্ষা করার সময় অন্য কাজ এগিয়ে নেওয়া।

**মনে রাখুন:** Processing একটি সাধারণ ধারণা। অন্যদিকে, multiprocessing হলো একাধিক process ব্যবহার করার একটি নির্দিষ্ট পদ্ধতি।

---

## ২. Multiprocessing কী?

**Multiprocessing** হলো একাধিক process ব্যবহার করে কাজ সম্পন্ন করার পদ্ধতি।

প্রতিটি process-এর সাধারণত নিজস্ব memory space এবং Python interpreter থাকে। তাই উপযুক্ত পরিস্থিতিতে একাধিক process একাধিক CPU core-এ একই সময়ে কাজ করতে পারে।

### উদাহরণ

- Image Processing
- Video Processing
- Large Mathematical Calculations
- Scientific Computation
- CPU-intensive Data Processing
- CPU-heavy Algorithms

**মনে রাখুন:** Multiprocessing বিশেষভাবে CPU-bound কাজের জন্য উপকারী। তবে process তৈরি, data transfer এবং communication-এর overhead থাকায় এটি সব সময় faster নয়।

---

## ৩. Process কী?

**Process** হলো একটি running program-এর instance।

যখন আমরা Python program চালাই, operating system সেই program চালানোর জন্য একটি process তৈরি করে।

একটি process অন্য process তৈরি করতে পারে। তৈরি করা process-কে child process এবং যে process তৈরি করে তাকে parent process বলা হয়।

```text
Python Program
      |
      ↓
  Main Process
      |
      +------ Child Process 1
      |
      +------ Child Process 2
      |
      +------ Child Process 3
```

---

## ৪. Main Process কী?

যে process থেকে Python program-এর execution শুরু হয়, তাকে সাধারণভাবে **Main Process** বলা হয়।

Python-এর `multiprocessing.current_process()` function দিয়ে বর্তমান process-এর object পাওয়া যায়।

```python
import multiprocessing

process = multiprocessing.current_process()

print(process)
print(process.name)
```

সম্ভাব্য Output:

```text
<_MainProcess name='MainProcess' parent=None started>
MainProcess
```

Output-এর exact representation Python version ও environment অনুযায়ী ভিন্ন হতে পারে।

## ৫. `multiprocessing.current_process()`

এই function বর্তমানে যে process code execute করছে, সেই process-এর object return করে।

```python
import multiprocessing

process = multiprocessing.current_process()

print("Process:", process)
print("Name:", process.name)
```

Child process-এর ভেতরে `current_process()` ব্যবহার করলে child process-এর object পাওয়া যাবে।

Process-এর নাম জানতে `.name` attribute ব্যবহার করা হয়।

## ৭. PID — Process ID

**PID (Process ID)** হলো operating system-এর দেওয়া process identifier।

বর্তমান process-এর PID পেতে `os.getpid()` ব্যবহার করা হয়।

```python
import os
import multiprocessing

process = multiprocessing.current_process()

print("Process Name:", process.name)
print("PID:", os.getpid())
```

`Process` object থেকেও child process-এর PID পাওয়া যায়:

```python
process.pid
```

মনে রাখুন:

- `os.getpid()` → বর্তমানে চলমান process-এর PID।
- `process.pid` → সংশ্লিষ্ট `Process` object-এর PID; process শুরু হওয়ার আগে এটি `None` হতে পারে।
- `os.getppid()` → বর্তমান process-এর parent process-এর PID।

## ৮. `ident` Attribute সম্পর্কে গুরুত্বপূর্ণ সংশোধন

`ident` সাধারণত `threading.Thread`-এর একটি attribute। এটি `multiprocessing.Process`-এর standard attribute নয়।

তাই multiprocessing-এর ক্ষেত্রে এইভাবে লিখবেন না:

```python
process.ident
```

এর পরিবর্তে ব্যবহার করুন:

```python
process.pid
```

অথবা:

```python
import os

print(os.getpid())
```

মনে রাখুন:

```text
Multiprocessing.Process → pid
threading.Thread        → ident
```

## ৯. `is_alive()`

কোনো process বর্তমানে চলমান কি না তা পরীক্ষা করতে `is_alive()` ব্যবহার করা হয়।

```python
import multiprocessing
import time

def task():
    time.sleep(3)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()

    print(process.is_alive())

    process.join()

    print(process.is_alive())
```

সম্ভাব্য Output:

```text
True
False
```

ব্যাখ্যা:

- Process চলমান থাকলে `True` return করে।
- Process শেষ হয়ে গেলে `False` return করে।
- Process শুরু হওয়ার আগেও `False` return করে।

## ১০. Parent Process এবং Child Process

যে process অন্য একটি process তৈরি করে, সেটি parent process।

যে process তৈরি হয়, সেটি child process।

```text
Parent Process
      |
      ↓
Child Process
```

উদাহরণ:

```python
import multiprocessing
import os

def task():
    print("Child PID:", os.getpid())
    print("Parent PID:", os.getppid())

if __name__ == "__main__":
    print("Main PID:", os.getpid())

    process = multiprocessing.Process(target=task)

    process.start()
    process.join()
```

এখানে:

- `os.getpid()` বর্তমান process-এর PID দেয়।
- `os.getppid()` parent process-এর PID দেয়।

## ১১. `multiprocessing.Process()`

নতুন process চালানোর জন্য `multiprocessing.Process()` ব্যবহার করা হয়।

### Syntax

```python
process = multiprocessing.Process(
    target=task
)
```

গুরুত্বপূর্ণ parameter:

| Parameter | কাজ |
|---|---|
| `target` | কোন callable execute হবে |
| `args` | Positional arguments পাঠায় |
| `kwargs` | Keyword arguments পাঠায় |
| `name` | Process-এর নাম নির্ধারণ করে |
| `daemon` | Process daemon হিসেবে চলবে কি না নির্ধারণ করে |

**গুরুত্বপূর্ণ:** `Process()` object তৈরি করে, কিন্তু এটি নিজে থেকেই নতুন process চালু করে না। নতুন process চালু করতে `start()` ব্যবহার করতে হয়।

---

## ১২. `target`

`target` দিয়ে নির্ধারণ করা হয় child process কোন function বা callable execute করবে।

```python
import multiprocessing

def task():
    print("Hello from child process")

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()
```

এখানে `target=task` অর্থ হলো child process-এ `task` function execute হবে।

---

## ১৩. `target=task` বনাম `target=task()`

### সঠিক

```python
process = multiprocessing.Process(target=task)
```

এখানে function-টিকে reference হিসেবে পাঠানো হয়েছে।

### ভুল

```python
process = multiprocessing.Process(target=task())
```

এখানে `task()` আগে execute হবে। তারপর function-এর return value `target` হিসেবে পাঠানো হবে, যা সাধারণত ভুল।

মনে রাখুন:

```text
target=task
    ↓
Function-টি পরে execute হবে
```

---

## ১৪. `start()`

`start()` method নতুন child process শুরু করে। Child process-এর মধ্যে target callable execute হয়।

```python
process.start()
```

Process execution-এর ধারণাগত flow:

```text
Process Object তৈরি
        ↓
     start()
        ↓
Child Process শুরু
        ↓
Target Callable Execute
```

একটি `Process` object সাধারণত একবারই start করা যায়।

---

## ১৫. `join()`

`join()` method calling process-কে অপেক্ষা করায় যতক্ষণ না নির্দিষ্ট child process শেষ হয়।

```python
process.start()
process.join()

print("Child process finished")
```

এখানে main process child process শেষ হওয়া পর্যন্ত অপেক্ষা করবে।

### গুরুত্বপূর্ণ

`join()` নিজে process বন্ধ করে না। এটি শুধু অপেক্ষা করে।

```text
start() → Process শুরু করে
join()  → Process শেষ হওয়া পর্যন্ত অপেক্ষা করে
```

`join(timeout=2)` ব্যবহার করলে সর্বোচ্চ নির্দিষ্ট সময় অপেক্ষা করা যায়। Timeout শেষ হলেও child process চলতে পারে।

## ১৬. `start()` বনাম `run()`

`start()` এবং `run()` এক জিনিস নয়।

### `start()`

```python
process.start()
```

নতুন child process চালু করে এবং সেখানে target callable execute করায়।

### `run()`

```python
process.run()
```

`run()` সরাসরি call করলে target callable বর্তমান process-এর মধ্যেই execute হয়। এটি নিজে থেকে নতুন process তৈরি করে না।

সাধারণ multiprocessing ব্যবহারে `start()` ব্যবহার করুন।

---

## ১৭. `if __name__ == "__main__":`

Multiprocessing program-এ main guard ব্যবহার করা গুরুত্বপূর্ণ, বিশেষ করে `spawn` start method-এর ক্ষেত্রে।

সঠিক structure:

```python
import multiprocessing

def task():
    print("Child process is running")

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()
```

Main guard কেন প্রয়োজন?

`spawn` পদ্ধতিতে child process নতুন Python interpreter চালু করে এবং main module import করতে পারে। Process তৈরির কোড guard-এর বাইরে থাকলে অনিচ্ছাকৃতভাবে আবার process তৈরি হতে পারে।

### গুরুত্বপূর্ণ নিয়ম

- Process তৈরির কোড main guard-এর ভেতরে রাখুন।
- Target function সাধারণত module-এর top level-এ সংজ্ঞায়িত করুন।
- `spawn` ব্যবহার করলে target function ও পাঠানো arguments picklable হওয়া প্রয়োজন।

Windows-এ এই বিষয়টি বিশেষভাবে গুরুত্বপূর্ণ। তবে ভালো portability-এর জন্য সব platform-এই main guard ব্যবহার করা উচিত।

## ১৮. Complete Basic Multiprocessing Program

```python
import multiprocessing

def task():
    print("Child process is running")

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

    print("Main process finished")
```

সম্ভাব্য Output:

```text
Child process is running
Main process finished
```

### Program Flow

```text
Program Start
     ↓
Main Process
     ↓
Create Process
     ↓
start()
     ↓
Child Process
     ↓
task()
     ↓
Child Finished
     ↓
join() returns
     ↓
Main Process continues
```

## ২১. Multiple Child Processes

একটি main process থেকে একাধিক child process তৈরি করা যায়।

```python
import multiprocessing

def task(number):
    print("Task:", number)

if __name__ == "__main__":
    p1 = multiprocessing.Process(
        target=task,
        args=(1,)
    )

    p2 = multiprocessing.Process(
        target=task,
        args=(2,)
    )

    p3 = multiprocessing.Process(
        target=task,
        args=(3,)
    )

    p1.start()
    p2.start()
    p3.start()

    p1.join()
    p2.join()
    p3.join()
```

সম্ভাব্য Output:

```text
Task: 2
Task: 1
Task: 3
```

অথবা:

```text
Task: 1
Task: 3
Task: 2
```

Output-এর order নিশ্চিত নয়। Operating system এবং process scheduling-এর কারণে execution order পরিবর্তিত হতে পারে।

## ২৫. `terminate()`

`terminate()` method দিয়ে একটি child process-কে জোরপূর্বক বন্ধ করার অনুরোধ করা যায়।

```python
import multiprocessing
import time

def task():
    while True:
        print("Running...")
        time.sleep(1)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()

    time.sleep(3)

    process.terminate()
    process.join()

    print("Process stopped")
```

### সতর্কতা

`terminate()` ব্যবহার করলে process স্বাভাবিকভাবে cleanup করার সুযোগ নাও পেতে পারে।

উদাহরণ:

- `finally` block execute নাও হতে পারে।
- File বা resource সঠিকভাবে close নাও হতে পারে।
- Lock, Queue বা Pipe-এর অবস্থা নষ্ট হতে পারে।

তাই সম্ভব হলে আগে cooperative shutdown ব্যবহার করুন। যেমন, `multiprocessing.Event` দিয়ে worker-কে কাজ থামানোর signal দেওয়া।

## ২৬. `kill()`

`kill()` method process-কে আরও জোরালোভাবে forcefully terminate করার জন্য ব্যবহার করা হয়।

```python
process.kill()
process.join()
```

`terminate()` এবং `kill()`-এর সুনির্দিষ্ট আচরণ operating system অনুযায়ী কিছুটা ভিন্ন হতে পারে।

মনে রাখুন:

- `terminate()` → Process forcefully terminate করার অনুরোধ করে।
- `kill()` → আরও জোরালো OS-level termination ব্যবহার করে।
- কোনোটিই স্বাভাবিক cleanup নিশ্চিত করে না।
- Process বন্ধ করার পর `join()` করে তার termination সম্পন্ন হয়েছে কি না নিশ্চিত হওয়া ভালো।

---

## ২৭. `exitcode`

Process শেষ হওয়ার পরে `exitcode` attribute দিয়ে তার exit status জানা যায়।

```python
import multiprocessing

def task():
    print("Working")

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

    print("Exit Code:", process.exitcode)
```

সাধারণ অর্থ:

- `0` → সাধারণত সফলভাবে শেষ হয়েছে।
- Non-zero → সাধারণত error বা abnormal termination নির্দেশ করে।
- `None` → Process এখনও শেষ হয়নি, অথবা exit status এখনও পাওয়া যায়নি।

POSIX system-এ signal-এর কারণে process শেষ হলে exit code negative-ও হতে পারে।

## ২৮. Process Lifecycle

```text
Process Object Created
          |
          ↓
        start()
          |
          ↓
    Child Process Runs
          |
          ↓
   Target Function Executes
          |
          ↓
    Process Terminates
          |
          ↓
      join() returns
```

মনে রাখুন, `join()` process-এর lifecycle-এর termination ঘটায় না। Process শেষ হওয়ার পরে `join()` return করে।

## ২৯. একটি Process Object একবারই Start করা যায়

একই `Process` object দ্বিতীয়বার start করা যায় না।

ভুল:

```python
process.start()
process.join()

process.start()  # RuntimeError হতে পারে
```

আরেকটি process চালাতে নতুন object তৈরি করুন।

```python
p1 = multiprocessing.Process(target=task)
p2 = multiprocessing.Process(target=task)

p1.start()
p2.start()

p1.join()
p2.join()
```

## ৩০. CPU-bound Task

যে task-এ বেশিরভাগ সময় CPU calculation করতে হয়, তাকে **CPU-bound task** বলে।

উদাহরণ:

- Large Mathematical Calculations
- Image Processing
- Video Encoding
- Scientific Computation
- Complex Algorithms
- CPU-intensive Data Processing

এই ধরনের কাজের জন্য multiprocessing উপকারী হতে পারে, যদি কাজগুলো parallelভাবে ভাগ করা যায় এবং overhead-এর তুলনায় যথেষ্ট computation থাকে।

---

## ৩১. I/O-bound Task

যে task-এ বেশিরভাগ সময় input/output operation-এর জন্য অপেক্ষা করতে হয়, তাকে **I/O-bound task** বলে।

উদাহরণ:

- File Reading/Writing
- Network Requests
- Database Queries
- API Requests
- External Service-এর response-এর জন্য অপেক্ষা

অনেক I/O-bound কাজের জন্য threading বা `asyncio` ভালো পছন্দ হতে পারে। তবে প্রয়োজন অনুযায়ী multiprocessing-ও ব্যবহার করা যায়।

---

## ৩২. Multiprocessing এবং GIL

**GIL (Global Interpreter Lock)** হলো standard GIL-enabled CPython-এর একটি mechanism, যা একই interpreter-এর একাধিক thread-এর Python bytecode একই সময়ে execute করার ক্ষেত্রে সীমাবদ্ধতা তৈরি করে।

Multiprocessing-এ আলাদা process ব্যবহার করা হয়। প্রতিটি process-এর নিজস্ব Python interpreter থাকে। তাই CPU-bound কাজকে একাধিক process-এ ভাগ করে একাধিক CPU core-এ parallel execution সম্ভব হতে পারে।

### সহজ ধারণা

```text
Multithreading
      ↓
Same Process
      ↓
Threads share process memory
      ↓
GIL can limit parallel Python bytecode execution
```

```text
Multiprocessing
      ↓
Multiple Processes
      ↓
Separate process memory
      ↓
Parallel execution may use multiple CPU cores
```

**নোট:** এই GIL ব্যাখ্যা standard GIL-enabled CPython-এর জন্য। Python-এর free-threaded build-ও রয়েছে, তাই GIL-এর প্রভাব সব Python configuration-এ একই নয়।

---

## ৩৩. Multiprocessing বনাম Multithreading

| বিষয় | Multiprocessing | Multithreading |
|---|---|---|
| Execution unit | Process | Thread |
| Memory | সাধারণত আলাদা | একই process-এর মধ্যে shared |
| CPU-bound task | ভালো choice হতে পারে | Standard CPython-এ GIL limitation থাকতে পারে |
| I/O-bound task | ব্যবহার করা যায় | প্রায়ই ভালো choice |
| Communication | তুলনামূলক জটিল | সাধারণত সহজ |
| Memory overhead | সাধারণত বেশি | সাধারণত কম |
| Isolation | তুলনামূলক বেশি | তুলনামূলক কম |
| Startup overhead | সাধারণত বেশি | সাধারণত কম |

### General Rule

```text
CPU-bound Task
       ↓
Multiprocessing বিবেচনা করুন
```

```text
I/O-bound Task
       ↓
Threading / Asyncio বিবেচনা করুন
```

এটি সাধারণ নিয়ম, কঠোর নিয়ম নয়। Task-এর ধরন, data size, platform এবং overhead বিবেচনা করতে হবে।

---

## ৩৪. Process-এর Separate Memory

প্রতিটি process-এর সাধারণত নিজস্ব memory space থাকে।

```python
import multiprocessing

number = 10

def task():
    print("Child:", number)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

    print("Parent:", number)
```

সম্ভাব্য Output:

```text
Child: 10
Parent: 10
```

Child process-এ সাধারণ Python variable পরিবর্তন করলেও parent-এর variable স্বয়ংক্রিয়ভাবে পরিবর্তিত হয় না।

```python
import multiprocessing

number = 10

def task():
    global number
    number = 50
    print("Child:", number)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

    print("Parent:", number)
```

সম্ভাব্য Output:

```text
Child: 50
Parent: 10
```

এখানে child process-এর পরিবর্তন parent process-এর variable-এ প্রতিফলিত হয়নি।

**নোট:** `fork` start method-এ child শুরুতে parent-এর memory-এর copy-on-write view পেতে পারে। তবুও সাধারণ Python variable-এর পরিবর্তন সাধারণত parent-এ ফিরে আসে না।

---

## ৩৫. Process-এর মধ্যে Data Share

Process-এর memory আলাদা হওয়ায় সাধারণ Python variable সরাসরি share করা যায় না।

Process-এর মধ্যে data পাঠানো বা share করার জন্য ব্যবহার করা যায়:

- `multiprocessing.Queue`
- `multiprocessing.Pipe`
- `multiprocessing.Value`
- `multiprocessing.Array`
- `multiprocessing.Manager`
- `multiprocessing.shared_memory`

একাধিক process একই shared data পরিবর্তন করলে synchronization প্রয়োজন হতে পারে।

সাধারণভাবে message পাঠানোর জন্য `Queue` এবং `Pipe` ব্যবহার করা সহজ ও নিরাপদ পদ্ধতি।

---

## ৩৬. `multiprocessing.Queue`

`Queue` ব্যবহার করে process-এর মধ্যে data বা message পাঠানো যায়।

```text
Process A
    |
    ↓
  Queue
    |
    ↓
Process B
```

উদাহরণ:

```python
import multiprocessing

def worker(queue):
    queue.put("Hello from child")

if __name__ == "__main__":
    queue = multiprocessing.Queue()

    process = multiprocessing.Process(
        target=worker,
        args=(queue,)
    )

    process.start()

    message = queue.get()
    print(message)

    process.join()
    queue.close()
```

Output:

```text
Hello from child
```

### গুরুত্বপূর্ণ বিষয়

- `put()` দিয়ে data পাঠানো হয়।
- `get()` দিয়ে data গ্রহণ করা হয়।
- Queue-তে data পাঠানোর সময় সাধারণত pickle ব্যবহার করে serialize করা হয়।
- পাঠানো object-টি picklable হতে হয়।

বড় data Queue-তে পাঠানোর সময় আগে producer process-কে `join()` করে বসে থাকলে deadlock হতে পারে, যদি Queue-এর buffer পূর্ণ হয়ে যায়। তাই data গ্রহণের order সঠিকভাবে পরিচালনা করা জরুরি।

---

## ৩৭. `multiprocessing.Pipe`

`Pipe` দুইটি process-এর মধ্যে communication করার জন্য ব্যবহার করা যায়।

```text
Process A
    |
    ↓
   Pipe
    |
    ↓
Process B
```

উদাহরণ:

```python
import multiprocessing

def worker(connection):
    connection.send("Hello from child")
    connection.close()

if __name__ == "__main__":
    parent_conn, child_conn = multiprocessing.Pipe()

    process = multiprocessing.Process(
        target=worker,
        args=(child_conn,)
    )

    process.start()

    print(parent_conn.recv())

    process.join()

    parent_conn.close()
```

Output:

```text
Hello from child
```

### গুরুত্বপূর্ণ Method

- `send()` → Data পাঠায়।
- `recv()` → Data গ্রহণ করে।
- `close()` → Connection বন্ধ করে।

Default `Pipe()` duplex connection তৈরি করে, অর্থাৎ দুই দিকেই data পাঠানো সম্ভব। One-way connection-ও তৈরি করা যায়।

---

## ৩৮. `multiprocessing.Pool`

অনেকগুলো একই ধরনের task থাকলে `Pool` ব্যবহার করা সুবিধাজনক।

`Pool` worker process-এর একটি group তৈরি করে এবং তাদের মধ্যে কাজ distribute করে।

উদাহরণ:

```python
import multiprocessing

def square(number):
    return number * number

if __name__ == "__main__":
    with multiprocessing.Pool() as pool:
        results = pool.map(
            square,
            [1, 2, 3, 4, 5]
        )

    print(results)
```

Output:

```text
[1, 4, 9, 16, 25]
```

এখানে:

1. `Pool()` worker process তৈরি করে।
2. `map()` প্রতিটি input-এর জন্য `square()` execute করায়।
3. Return value-গুলো list হিসেবে পাওয়া যায়।
4. `with` block শেষ হলে pool-এর worker process-গুলো বন্ধ করার ব্যবস্থা করা হয়।

---

## ৩৯. `Pool.map()`

Syntax:

```python
pool.map(function, iterable)
```

উদাহরণ:

```python
results = pool.map(square, [1, 2, 3, 4, 5])
```

এটি conceptually নিচের কাজগুলো করে:

```text
1 → square(1)
2 → square(2)
3 → square(3)
4 → square(4)
5 → square(5)
```

Result list-এ input-এর order বজায় থাকে, যদিও worker-গুলো কাজের জন্য ভিন্ন সময়ে শুরু বা শেষ হতে পারে।

### গুরুত্বপূর্ণ

`Pool` ব্যবহার করার সময়:

- Worker function সাধারণত module-এর top level-এ সংজ্ঞায়িত করুন।
- Function ও argument-গুলো picklable হতে হবে।
- Pool তৈরির কোড main guard-এর ভেতরে রাখুন।
- `map()` একাধিক input-এর result সংগ্রহ করে list return করে।

---

## ৪০. `Pool` কেন ব্যবহার করব?

Pool ছাড়া অনেকগুলো process নিজে তৈরি ও পরিচালনা করতে হতে পারে।

```python
p1 = multiprocessing.Process(...)
p2 = multiprocessing.Process(...)
p3 = multiprocessing.Process(...)
```

অনেকগুলো independent task থাকলে `Pool` worker process-গুলো পুনরায় ব্যবহার করতে পারে এবং কাজ পরিচালনা সহজ করে।

```text
Many Tasks
    ↓
Process Pool
    ↓
Worker Processes
    ↓
Results
```

Pool-এর worker সংখ্যা `processes` parameter দিয়ে নির্ধারণ করা যায়।

```python
with multiprocessing.Pool(processes=4) as pool:
    results = pool.map(square, [1, 2, 3, 4, 5])
```

এখানে চারটি worker process নির্ধারণ করা হয়েছে। তবে worker সংখ্যা বাড়ালেই সব program দ্রুত হবে না।

---

## ৪১. `daemon` Process

`daemon` attribute দিয়ে process daemon process কি না বোঝা যায়।

```python
process = multiprocessing.Process(
    target=task,
    daemon=True
)
```

Multiprocessing-এর daemon process সম্পর্কে গুরুত্বপূর্ণ বিষয়:

- Parent process শেষ হলে daemon child process-কে terminate করা হয়।
- Daemon process নিজে নতুন child process তৈরি করতে পারে না।
- গুরুত্বপূর্ণ কাজের জন্য daemon process-এর ওপর নির্ভর করা উচিত নয়, কারণ parent শেষ হলে কাজটি মাঝপথে বন্ধ হতে পারে।

Daemon process এবং সাধারণ process-এর আচরণ বুঝে ব্যবহার করুন।

---

## ৪২. `close()`

`Process` object-এর সঙ্গে যুক্ত কিছু resource release করতে `close()` ব্যবহার করা হয়।

```python
import multiprocessing

def task():
    print("Working")

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

    process.close()
```

### গুরুত্বপূর্ণ

- `close()` process-কে terminate করার method নয়।
- Process এখনও চলমান থাকলে `close()` সাধারণত `ValueError` raise করে।
- `close()` করার পরে ওই `Process` object আবার ব্যবহার বা start করা যায় না।

মনে রাখুন:

```text
join()  → Process শেষ হওয়া পর্যন্ত অপেক্ষা
close() → Process object-এর resource release
```

---

## ৪৩. Multiprocessing-এর সুবিধা

১. CPU-intensive কাজের জন্য কার্যকর হতে পারে।

২. একাধিক CPU core ব্যবহার করে parallel execution সম্ভব।

৩. Process-গুলোর memory আলাদা থাকায় isolation তুলনামূলক বেশি।

৪. একটি child process ব্যর্থ হলে parent process স্বয়ংক্রিয়ভাবে ব্যর্থ হতেই হবে এমন নয়।

৫. Independent task একাধিক process-এ ভাগ করা যায়।

৬. উপযুক্ত task-এর ক্ষেত্রে মোট execution time কমানো সম্ভব।

---

## ৪৪. Multiprocessing-এর অসুবিধা

১. Memory usage সাধারণত বেশি।

২. Process তৈরি ও পরিচালনায় overhead থাকে।

৩. Process-এর মধ্যে communication তুলনামূলক জটিল।

৪. Data serialization বা pickling-এর overhead হতে পারে।

৫. Debugging ও error handling কঠিন হতে পারে।

৬. Shared data ব্যবহার করলে synchronization প্রয়োজন হতে পারে।

৭. ছোট task-এর ক্ষেত্রে multiprocessing ধীরও হতে পারে।

---

## ৪৫. কখন Multiprocessing ব্যবহার করব?

Multiprocessing বিবেচনা করুন যখন:

- Task CPU-intensive।
- কাজগুলো একে অপরের থেকে যথেষ্ট independent।
- কাজগুলো parallelভাবে ভাগ করা যায়।
- একাধিক CPU core ব্যবহার করলে উপকার পাওয়া যায়।
- Parallel execution-এর সুবিধা overhead-এর চেয়ে বেশি।

উদাহরণ:

- Image Processing
- Video Processing
- Scientific Computation
- Large Mathematical Operations
- CPU-intensive Data Processing

---

## ৪৬. কখন Multiprocessing এড়িয়ে চলব?

Multiprocessing সবসময় faster নয়।

যদি কাজ খুব ছোট হয়, তাহলে process creation, communication ও serialization-এর overhead actual calculation-এর চেয়ে বেশি হতে পারে।

উদাহরণ:

- Very Small Calculations
- Simple Print Operations
- Tiny Tasks
- ঘন ঘন process-এর মধ্যে data পাঠানো
- এমন I/O-bound কাজ, যা threading বা `asyncio` দিয়ে সহজে করা যায়

সঠিক পদ্ধতি বেছে নেওয়ার আগে প্রয়োজনে benchmark করুন।

## ৪৭. Important Process Methods

| Method / Function | কাজ |
|---|---|
| `start()` | Child process শুরু করে |
| `run()` | Target callable execute করে; সরাসরি call করলে নতুন process শুরু হয় না |
| `join()` | Process শেষ হওয়া পর্যন্ত অপেক্ষা করে |
| `is_alive()` | Process চলছে কি না জানায় |
| `terminate()` | Process forcefully terminate করার অনুরোধ করে |
| `kill()` | Process-কে আরও জোরালোভাবে terminate করে |
| `close()` | Process object-এর associated resources release করে |
| `current_process()` | বর্তমান process-এর object দেয় |

---

## ৪৮. Important Process Attributes

| Attribute | কাজ |
|---|---|
| `name` | Process-এর নাম |
| `pid` | Process-এর OS-level ID |
| `exitcode` | Process-এর exit status |
| `daemon` | Process daemon কি না |

**মনে রাখুন:** `multiprocessing.Process`-এর standard attribute হিসেবে `ident` ব্যবহার করবেন না। `ident` হলো `threading.Thread`-এর attribute।

## ৪৯. Complete Multiprocessing Example

```python
import multiprocessing
import os
import time

def worker(number):
    process = multiprocessing.current_process()

    print(
        f"Name: {process.name}, "
        f"PID: {os.getpid()}, "
        f"Task: {number}"
    )

    time.sleep(2)

    print(f"Task {number} finished")


if __name__ == "__main__":
    processes = []

    for i in range(3):
        process = multiprocessing.Process(
            target=worker,
            args=(i,),
            name=f"Worker-{i}"
        )

        processes.append(process)
        process.start()

    for process in processes:
        process.join()

    print("All processes finished")
```

সম্ভাব্য Output:

```text
Name: Worker-0, PID: 1234, Task: 0
Name: Worker-1, PID: 1235, Task: 1
Name: Worker-2, PID: 1236, Task: 2

Task 0 finished
Task 1 finished
Task 2 finished

All processes finished
```

এখানে PID এবং output-এর exact order তোমার system-এ ভিন্ন হতে পারে।

## ৫০. Multiprocessing Mental Model

```text
Python Program
       |
       ↓
  Main Process
       |
       +------------+------------+
       |            |            |
       ↓            ↓            ↓
   Process 1    Process 2    Process 3
       |            |            |
       ↓            ↓            ↓
   Task A       Task B       Task C
```

প্রতিটি process-এর সাধারণত থাকে:

- নিজস্ব execution flow
- নিজস্ব memory space
- নিজস্ব PID
- নিজস্ব Python interpreter

একাধিক process একাধিক CPU core ব্যবহার করতে পারে, তবে operating system, hardware এবং workload-এর ওপর প্রকৃত parallelism নির্ভর করে।

## ৫৩. Final Revision

### Multiprocessing

```text
Multiprocessing
      ↓
Multiple Processes
      ↓
Separate Process Memory
      ↓
Multiple CPU Cores ব্যবহার করতে পারে
      ↓
CPU-bound Tasks-এর জন্য উপকারী হতে পারে
```

### Process Lifecycle

```text
Process()
    ↓
start()
    ↓
Child Process Runs
    ↓
Target Callable Executes
    ↓
Process Finishes
    ↓
join() returns
```

### CPU-bound বনাম I/O-bound

```text
CPU-bound
    ↓
Multiprocessing বিবেচনা করুন
```

```text
I/O-bound
    ↓
Threading / Asyncio বিবেচনা করুন
```

### One-Line Memory Rule

**Multiprocessing হলো একাধিক process ব্যবহার করে কাজ সম্পন্ন করার পদ্ধতি। প্রতিটি process-এর সাধারণত আলাদা memory থাকে এবং উপযুক্ত CPU-bound task-এর ক্ষেত্রে একাধিক CPU core ব্যবহার করে parallel execution সম্ভব হয়।**
