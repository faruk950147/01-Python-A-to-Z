Python Multiprocessing — বাংলা Notes

১. Processing কী?

Processing মানে হলো কোনো input/data নিয়ে কাজ করে useful output তৈরি করা।

Python-এ কাজ করার কয়েকটি উপায়:
- Single Processing
- Multithreading
- Multiprocessing
- Asynchronous Programming


২. Multiprocessing কী?

Multiprocessing হলো একাধিক process ব্যবহার করে কাজ সম্পন্ন করা।

প্রতিটি process-এর সাধারণত নিজস্ব memory space থাকে।

CPU-heavy কাজের ক্ষেত্রে multiprocessing খুব উপকারী, কারণ একাধিক process আলাদা CPU core ব্যবহার করতে পারে।

উদাহরণ:
- Image Processing
- Video Processing
- Large Mathematical Calculations
- Scientific Calculations
- Data Processing
- Machine Learning Computation
- CPU-heavy Algorithms


৩. Process কী?

Process হলো কোনো program-এর running instance।

যখন আমরা Python program চালাই, operating system সেই program-এর জন্য একটি process তৈরি করে।

একটি process আবার একাধিক child process তৈরি করতে পারে।

Python Program
      |
      ↓
 Main Process
      |
      +------ Child Process 1
      |
      +------ Child Process 2
      |
      +------ Child Process 3


৪. Main Process কী?

যে process থেকে Python program-এর execution শুরু হয় তাকে Main Process বলে।

উদাহরণ:

process = multiprocessing.current_process()

print(process)

সম্ভাব্য Output:

<_MainProcess name='MainProcess' parent=None started>

৯. is_alive()

কোনো process বর্তমানে চলছে কিনা তা check করার জন্য is_alive() ব্যবহার করা হয়।

process.is_alive()

উদাহরণ:

import multiprocessing
import time

def task():
    time.sleep(3)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()

    print(process.is_alive())

    process.join()

    print(process.is_alive())

সম্ভাব্য Output:

True
False

১৫. join()

join() calling process-কে অপেক্ষা করায় যতক্ষণ না child process শেষ হয়।

এখানে main process child process শেষ হওয়া পর্যন্ত অপেক্ষা করবে।


১৬. start() বনাম join()

→ Process শুরু করে

→ Process শেষ হওয়া পর্যন্ত অপেক্ষা করে

সহজভাবে:

start() = Start the process
join() = Wait for the process

১৮. Complete Basic Multiprocessing Program

import multiprocessing

def task():
    print("Child process is running")

if __name__ == "__main__":

    process = multiprocessing.Process(
        target=task
    )

    process.join()

    print("Main process finished")


Program Flow:

Program Start
     ↓
Main Process
     ↓
Create Process
     ↓

     ↓
Child Process
     ↓

Child Finished
     ↓
join() returns
     ↓
Main Process continues

২২. Multiple Child Processes

একাধিক child process তৈরি করা যায়।

import multiprocessing

def task(number):
    print("Task:", number)

if __name__ == "__main__":

    p1 = multiprocessing.Process(
        target=task,
        args=(1,)
    )

    p2 = multiprocessing.Process(
        target=task,
        args=(2,)
    )

    p3 = multiprocessing.Process(
        target=task,
        args=(3,)
    )

    p1.start()
    p2.start()
    p3.start()

    p1.join()
    p2.join()
    p3.join()

Output order fixed নয়।

যেমন:

Task: 2
Task: 1
Task: 3

অথবা:

Task: 1
Task: 3
Task: 2

Operating System ঠিক করে কোন process কখন CPU time পাবে।

২৬. terminate()

চলমান process terminate করার জন্য:

process.terminate()

উদাহরণ:

import multiprocessing
import time

def task():
    while True:
        print("Running...")
        time.sleep(1)

if __name__ == "__main__":

    process = multiprocessing.Process(target=task)

    process.start()

    time.sleep(3)

    process.terminate()
    process.join()

    print("Process terminated")

Important:

terminate() process-কে normal cleanup করার সুযোগ নাও দিতে পারে।

তাই process যদি ব্যবহার করে:
- Files
- Locks
- Database connections
- Other resources

তাহলে সতর্ক থাকতে হবে।

৩৫. Multiprocessing এবং GIL

CPython-এ GIL অর্থাৎ Global Interpreter Lock একই process-এর একাধিক thread-এর Python bytecode একই সময়ে execute করার ক্ষেত্রে limitation তৈরি করে।

Multiprocessing আলাদা process ব্যবহার করে।

প্রতিটি process-এর নিজস্ব Python interpreter এবং সাধারণত আলাদা memory space থাকে।

তাই CPU-bound program একাধিক process ব্যবহার করে multiple CPU core ব্যবহার করতে পারে।

সহজভাবে:

Multithreading
    ↓
Same Process
    ↓
Shared Memory
    ↓
GIL matters


Multiprocessing
    ↓
Multiple Processes
    ↓
Separate Memory
    ↓
Multiple CPU Cores


৩৬. Multiprocessing বনাম Multithreading

Multiprocessing:
- Unit → Process
- Memory → Separate
- CPU-bound → ভালো choice
- I/O-bound → ব্যবহার করা যায়
- Communication → বেশি complex
- Memory usage → বেশি
- Isolation → বেশি
- Creation overhead → বেশি

Multithreading:
- Unit → Thread
- Memory → Same process-এর মধ্যে shared
- CPU-bound → CPython-এ GIL limitation
- I/O-bound → সাধারণত ভালো
- Communication → সহজ
- Memory usage → কম
- Isolation → কম
- Creation overhead → কম


General Rule:

CPU-bound
    ↓
Multiprocessing


I/O-bound
    ↓
Threading / Asyncio

এটি একটি general rule, strict rule নয়।


৩৭. Process-এর Separate Memory

Process-এর সাধারণত আলাদা memory space থাকে।

উদাহরণ:

import multiprocessing

number = 10

def task():
    print("Child:", number)

if __name__ == "__main__":
    process = multiprocessing.Process(target=task)

    process.start()
    process.join()

Child process সাধারণ Python data-এর নিজের process-specific view/copy পায়।

Child যদি normal Python variable পরিবর্তন করে, সেই পরিবর্তন সরাসরি parent-এর variable পরিবর্তন করে না।

৩৯. multiprocessing.Queue

Queue ব্যবহার করে process-এর মধ্যে message/data পাঠানো যায়।

multiprocessing.Queue()

সহজভাবে:

Process A
    ↓
  Queue
    ↓
Process B

উদাহরণ:

import multiprocessing

def worker(queue):
    queue.put("Hello from child")

if __name__ == "__main__":

    queue = multiprocessing.Queue()

    process = multiprocessing.Process(
        target=worker,
        args=(queue,)
    )

    process.start()

    print(queue.get())

    process.join()

Output:

Hello from child


৪০. multiprocessing.Pipe

Pipe process-এর মধ্যে communication করার জন্য ব্যবহার করা হয়।

multiprocessing.Pipe()

সহজভাবে:

Process A
    |
   Pipe
    |
Process B

উদাহরণ:

import multiprocessing

def worker(connection):
    connection.send("Hello from child")
    connection.close()

if __name__ == "__main__":

    parent_conn, child_conn = multiprocessing.Pipe()

    process = multiprocessing.Process(
        target=worker,
        args=(child_conn,)
    )

    process.start()

    print(parent_conn.recv())

    process.join()

Output:

Hello from child


৪১. multiprocessing.Pool

অনেকগুলো similar task থাকলে Pool ব্যবহার করা সুবিধাজনক।

Pool worker process-এর একটি group তৈরি করে এবং task-গুলো তাদের মধ্যে distribute করে।

উদাহরণ:

import multiprocessing

def square(number):
    return number * number

if __name__ == "__main__":

    with multiprocessing.Pool() as pool:

        results = pool.map(
            square,
            [1, 2, 3, 4, 5]
        )

    print(results)

Output:

[1, 4, 9, 16, 25]


৪২. Pool.map()

Syntax:

pool.map(function, iterable)

উদাহরণ:

results = pool.map(
    square,
    [1, 2, 3, 4, 5]
)

Conceptually:

1 → square()
2 → square()
3 → square()
4 → square()
5 → square()

Result list হিসেবে পাওয়া যায়।

৪৬. কখন Multiprocessing ব্যবহার করব?

যখন:

✓ Task CPU-intensive
✓ Tasks mostly independent
✓ Multiple CPU cores available
✓ Parallel execution সাহায্য করবে
✓ কাজটি যথেষ্ট বড় যাতে multiprocessing overhead justify হয়

উদাহরণ:

Image Processing
Video Processing
Scientific Computation
Large Mathematical Operations
CPU-heavy Data Processing


৪৭. কখন Multiprocessing Avoid করব?

Multiprocessing সবসময় faster নয়।

যদি task খুব ছোট হয়, তাহলে process creation এবং communication overhead actual কাজের চেয়ে বেশি হতে পারে।

উদাহরণ:

Very Small Calculations
Simple Print Operations
Tiny Tasks
Frequent Shared-state Communication

৫০. Complete Multiprocessing Example

import multiprocessing
import os
import time

def worker(number):

    process = multiprocessing.current_process()

    print(
        f"Name: {process.name}, "
        f"PID: {os.getpid()}, "
        f"Task: {number}"
    )

    time.sleep(2)

    print(f"Task {number} finished")


if __name__ == "__main__":

    processes = []

    for i in range(3):

        process = multiprocessing.Process(
            target=worker,
            args=(i,),
            name=f"Worker-{i}"
        )

        processes.append(process)
        process.start()

    for process in processes:
        process.join()

    print("All processes finished")


সম্ভাব্য Output:

Name: Worker-0, PID: 1234, Task: 0
Name: Worker-1, PID: 1235, Task: 1
Name: Worker-2, PID: 1236, Task: 2

Task 0 finished
Task 1 finished
Task 2 finished

All processes finished

Output-এর exact order guaranteed নয়।

Python Program
       |
       ↓

       |
       +------------+------------+
       |            |            |
       ↓            ↓            ↓
 Process 1      Process 2     Process 3
       |            |            |
       ↓            ↓            ↓
   CPU Core     CPU Core     CPU Core
