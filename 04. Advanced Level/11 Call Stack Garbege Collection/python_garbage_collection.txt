GARBAGE COLLECTION IN PYTHON

Python-এ Garbage Collection হলো এমন একটি প্রক্রিয়া, যার মাধ্যমে আর ব্যবহার না হওয়া (unused) 
object গুলোকে মেমোরি থেকে সরিয়ে দেওয়া হয়, যাতে মেমোরি অপচয় না হয়।

Garbage Collection is the automatic process of freeing memory by removing objects
that are no longer used by a program.

HOW IT WORKS:
Python mainly uses Reference Counting to manage memory.
Each object keeps track of how many references point to it.
When reference count becomes zero, the object is deleted.

PROBLEM:
Reference counting cannot handle circular references.

SOLUTION:
Python also uses Generational Garbage Collection to remove circular references.

TYPES:
1. Reference Counting
2. Generational Garbage Collection

GENERATIONS:
Generation 0 - New objects
Generation 1 - Medium-lived objects
Generation 2 - Long-lived objects

IMPORTANT:
gc.collect() can be used to manually trigger garbage collection.

INTERVIEW LINE:
Python uses reference counting as its primary garbage collection method
and generational garbage collection to handle circular references.
