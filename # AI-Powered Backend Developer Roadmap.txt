# ধাপ ৩: RAG + Embeddings

### RAG Architecture

```text
Documents
    ↓
Chunking
    ↓
Embeddings
    ↓
Vector Database
    ↓
User Question
    ↓
Similarity Search
    ↓
Relevant Context
    ↓
LLM
    ↓
Answer
```

আপনি যেহেতু PostgreSQL জানেন, শুরুতে PostgreSQL-এর সঙ্গে `pgvector` ব্যবহার করে Vector Search শেখা ভালো।

# ধাপ ৪: Celery + Redis + AI Agents

## ৫ম সপ্তাহ

AI API response আসতে সময় লাগতে পারে। তাই production application-এর জন্য background processing শেখা গুরুত্বপূর্ণ।

### Celery Architecture

```text
Django API
    ↓
Celery Task
    ↓
Redis
    ↓
Worker
    ↓
OpenAI API
    ↓
Database
```

Example:

```python
@shared_task
def generate_product_description(product_id):
    ...
```

এভাবে AI-related heavy tasks background-এ execute করতে পারবেন।

## AI Agents

প্রথমে simple tool-based agent দিয়ে শুরু করুন।

### Basic Agent Architecture

```text
LLM
 ↓
Tool Selection
 ↓
Tool Execution
 ↓
Tool Result
 ↓
LLM
 ↓
Final Response
```

### Example

User:

```text
"আমার order #123 কোথায়?"
```

AI:

```text
get_order_status()
        ↓
PostgreSQL
        ↓
Order Information
        ↓
LLM
        ↓
Final Response
```

AI তখন database থেকে order status নিয়ে user-কে উত্তর দিতে পারবে।
